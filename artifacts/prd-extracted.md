# 一、产品总纲

## 1.1 产品背景与目标

通用能碳平台面向工业企业及园区型组织的能源数据管理、能源监测分析、组织温室气体核算、核查支撑、预算预测、能效优化和碳资产履约场景。产品一期以“数据可采、口径可算、结果可查、来源可追、风险可提示、建议可解释”为目标，形成从基础数据到经营策略的闭环。

| 一期定位：标准满足型、研发可落地的业务功能版本。优先实现主数据、台账、计算、分析、核算、版本快照、预警、策略建议和台账导出；不承诺自动控制、自动交易、第三方认证结论或复杂算法寻优。 |
| --- |

# 二、统一数据架构与公共规则

## 2.1 核心数据对象

| 对象 | 定义 | 关键字段示例 |
| --- | --- | --- |
| 用能单元 | 企业、一级用能单元、二级用能单元的组织和能源归属主数据。 | unit_id、parent_id、level、type、name、status |
| 能源品种 | 能源类别、名称、计量单位和折标参数。 | energy_id、category、name、unit、factor、factor_unit |
| 能源量记录 | 能源消费、回收能源、能源产出和外供能源的周期数据。 | record_id、period、org_id、energy_id、role、quantity、unit、tce |
| 能源成本 | 按能源品种和月份维护的企业级成本数据。 | year、month、energy_id、cost、currency_unit |
| 能源转换关系 | 投入记录与产出记录之间的转换场景。 | relation_id、scene、unit_id、input_ids、output_ids、efficiency、loss |
| 运营指标 | 产量、业务量和经济指标。 | indicator_id、category、name、unit、org_id、period、value |
| 重点设备 | 设备档案及所属用能单元。 | device_id、type、name、unit_id、main_energy_id |

| 碳核算清单项 | 活动数据、因子/参数、排放量和来源。 | item_id、task_id、source_type、activity、factor_id、parameters、emission |
| 正式清单快照 | 确认时冻结的只读核算版本。 | snapshot_id、task_id、version、confirmed_by、confirmed_at |

| 核查支撑材料 | 核算基础材料和排放源支撑文件。 | material_id、task_id、item_id、file_ref、status |
| 预算 | 能源/碳预算目标、预测方法和版本。 | budget_id、type、year、scope、target、forecast_method、version |
| 碳资产 | 配额和抵销资产的数量、余额与本期预计可用量。 | asset_id、type、market、cycle、quantity、available、eligible |

## 2.2 组织范围与层级

统一层级为：企业（全厂）→ 一级用能单元 → 二级用能单元。设备不作为主组织层级，单独归属至二级或一级用能单元。

一级用能单元用于能源分配、预算分解和主要分析对象；二级用能单元用于能源利用、工序/系统分析和设备归属。

所有下拉选项必须动态引用“能碳数据采集—用能单元”主数据，不允许在业务页面硬编码“生产单元A/B”等示例名称。

删除被能源数据、运营数据、设备、对标目标或碳核算引用的用能单元时应拦截，并提示引用位置。

## 2.3 能源数据角色与能流阶段

| 能源数据角色 | 允许归属 | 能流含义 | 处理规则 |
| --- | --- | --- | --- |
| 能源消费 | 企业/一级/二级 | 企业级形成能源输入控制量；一级形成能源分配；二级形成能源利用。 | 同一层级内汇总；父子层级不得重复相加。 |
| 回收能源 | 一级/二级 | 形成回收来源或能源转换投入候选。 | 不得直接作为企业边界输入重复计入综合能耗。 |
| 能源产出 | 一级/二级 | 形成能源转换产出或无投入自产能源。 | 需通过转换关系区分“有投入转换”和“无投入自产”。 |
| 外供能源 | 企业/一级/二级 | 形成企业边界外部输出。 | 用于边界平衡和净购入等计算，不作为内部利用。 |

| 统一能流业务语言：能源输入—能源转换—能源分配—能源利用—外部输出—未分配量。未分配量属于管理口径差额，不等同于物理损失；转换损失仅在投入与产出关系完整时计算。 |

## 2.5 计算与精度规则

| 指标 | 规则 | 精度/异常 |
| --- | --- | --- |
| 折标量 | 实物量 × 折标系数；根据系数单位完成kgce/tce换算。 | 内部保留≥6位小数；页面通常2位，百分比1位。 |
| 强度指标 | 分子指标 ÷ 分母运营指标；组织范围和期间必须一致。 | 分母缺失或为0时显示“暂不可计算”，不得显示0。 |
| 转换效率 | 转换产出折标量 ÷ 转换投入折标量 ×100%。 | 无投入自产场景不计算效率；缺系数显示待补。 |
| 未分配量 | 本级控制量－下级归属量（按同一能源、范围和期间）。 | 可以为负值并标记需核验，不自动解释为损失。 |
| 碳排放量 | 活动数据 × 综合因子，或按参数组公式计算。 | 保留计算参数、公式、来源和版本。 |
| 预算预测 | 一期采用可配置的固定方法，不由大模型直接预测。 | 展示方法、数据截止期、更新时间和版本。 |
| 履约缺口 | 预计履约需求－可用配额－本周期预计可抵销量。 | 资产余额与本期预计可用量分开展示。 |

## 2.6 统一状态、版本和缺失处理

| 状态 | 触发条件 | 页面行为 |
| --- | --- | --- |
| 正常/可用 | 数据完整且未触发异常规则。 | 常规展示。 |
| 关注/预警 | 偏差接近或超过关注阈值。 | 橙色标签并支持查看详情。 |
| 异常/未达标 | 超过异常阈值或目标未达成。 | 红色标签，展示依据和建议。 |
| 待补/缺失 | 关键值、因子、凭证或运营分母缺失。 | 不得默认为0；关键缺失可阻断正式确认。 |
| 待复核 | 数据已提交但需复核。 | 显示状态，允许有权限人员处理。 |
| 草稿结果 | 碳核算或预算尚未正式确认。 | 可编辑/重新计算，并显示来源变化提示。 |
| 正式/已锁定 | 正式清单快照或已生效预算版本。 | 只读；变更创建新版本。 |
| 无数据/无对比期 | 筛选结果为空或缺少同期。 | 显示“--/无数据/无对比期”，不得展示真实0。 |

## 2.7 跨模块上下文与来源追溯

跨模块跳转应携带组织范围、统计周期/核算年度、能源品种、对象、指标及结果版本等可复用上下文。

所有计算结果应支持查看来源：能源结果追溯至能源量记录和折标参数；碳结果追溯至活动数据、因子/参数和公式。

正式清单快照冻结后，上游数据变化不覆盖历史版本；当前任务显示“来源已变化”，由用户决定创建编辑副本更新。

导出内容必须与当前筛选条件、状态、版本和用户权限一致。
