# 碳排放因子库：字典与状态对接说明

## 1. 文档定位

本文档用于产品经理与后端研发对接“碳排放因子库”页面。

本文档只说明三件事：

1. 页面有哪些字典，后端需要维护哪些编码和值；
2. 不同因子类型需要显示哪些参数；
3. 页面中的状态分别代表什么，什么情况下允许查看、编辑、选择和删除。

本文档不展开接口路径、数据库SQL和前端实现方式。后端可以根据本文档自行设计表结构和接口，但页面展示名称、编码含义、参数边界和状态含义需要保持一致。

## 2. 因子库与核算清单的边界

因子库维护“可以跨核算期复用的参数”。核算清单维护“本次核算期间发生的活动数据和核算结果”。

| 数据内容 | 进入因子库 | 应维护的位置 |
| --- | --- | --- |
| 排放因子、NCV、CC、OF、Bo、MCF、GWP、逸散系数 | 是 | 碳排放因子库 |
| 方法学常数 44/12 | 是 | 碳排放因子库/公共字典 |
| 燃料消费量 | 否 | 核算清单/活动数据 |
| 电量、热量、运输周转量 | 否 | 核算清单/活动数据 |
| 原料消耗量、产量、库存变化 | 否 | 核算清单/活动数据 |
| 废水量、COD、BOD、COD去除量、污泥COD | 否 | 核算清单/监测数据 |
| 碳输入量、碳输出量、期初期末库存 | 否 | 物料平衡核算清单 |
| 冷媒、SF₆、灭火剂补充量/回收量/泄漏量 | 否 | 核算清单/监测数据 |
| CEMS浓度、烟气流量、运行时间、实测排放量 | 否 | CEMS监测模块 |
| 本次核算产生的排放量、CO₂e结果 | 否 | 核算清单/正式核算快照 |

后端需要特别注意：活动数据不能因为带有“企业实测”来源，就被保存成因子参数。

## 4. 因子类型字典

因子类型决定新增弹窗加载哪些参数。只有“可新增普通因子”为“是”的类型，才能出现在“新增因子”下拉框。

| code | 页面名称 | 是否允许普通新增 | 页面用途 |
| --- | --- | ---: | --- |
| `fuelParameter` | 参数合成因子型｜燃料燃烧 | 是 | 维护燃料燃烧可复用参数 |
| `direct` | 直接因子型｜电力、热力、运输 | 是 | 维护可直接参与核算的结果因子 |
| `processParameter` | 工艺参数型｜碳酸盐分解 | 是 | 维护工艺纯度和工艺排放参数 |
| `wastewaterParameter` | 废水参数型｜厌氧处理 | 是 | 维护Bo、MCF、GWP等参数 |
| `fugitive` | 逸散型｜冷媒/灭火器/六氟化硫 | 是 | 维护常规逸散率和对应GWP |
| `balance` | 物料平衡型｜含碳原料/产品 | 否 | 仅作为核算模板 |
| `recoveryParameter` | 回收/销毁扣减型｜CH₄回收与火炬销毁 | 否 | 仅作为核算模板 |
| `measured` | 实测型｜CEMS连续监测 | 否 | 仅作为监测配置 |

### 4.1 各类型的参数边界

| 因子类型 | 因子库中维护 | 不得录入因子库 |
| --- | --- | --- |
| 燃料燃烧 | NCV、CC、OF、44/12 | 燃料消费量、批次量、月度消耗量 |
| 直接因子 | 电力/热力/运输因子、气体、单位、适用年度/范围 | 电量、热量、运输周转量 |
| 工艺参数 | 原料纯度、CO₂排放因子 | 原料消耗量、产量、库存变化 |
| 废水参数 | Bo、MCF、GWP | 废水量、COD/BOD、COD去除量、污泥COD |
| 逸散型 | 设备/物质常规逸散率、对应GWP100 | 填充量、补充量、回收量、泄漏量 |
| 物料平衡 | 44/12等方法学常数 | 碳输入量、碳输出量、库存变化 |
| 回收/销毁 | 氧化系数、销毁效率 | 回收量、外供量、火炬量、气体浓度 |
| CEMS | 监测规则和设备配置不属于普通因子 | 浓度、烟气流量、运行时间、实测排放量 |

## 5. 新增弹窗参数字典

以下参数由因子类型自动加载。后端应根据因子类型返回参数定义，不能由前端自由增加参数。

### 5.1 燃料燃烧

| parameter_code | 页面名称 | 单位 | 是否可编辑 | 是否需要材料 |
| --- | --- | --- | ---: | ---: |
| `ncv` | 低位发热量 NCV | GJ/t、GJ/Nm³等 | 是 | 按来源判断 |
| `cc` | 单位热值含碳量 CC | tC/TJ等 | 是 | 按来源判断 |
| `of` | 碳氧化率 OF | % | 是 | 按来源判断 |
| `mw` | 碳转化为二氧化碳系数 | —，展示44/12 | 否 | 否 |

计算关系：`排放量 = 燃料消耗量 × NCV × CC ÷ 1000 × OF × 44/12`。燃料消耗量来自核算清单，不在弹窗中录入。

### 5.2 直接因子

直接因子参数名称和单位必须联动：

| parameter_code | 参数名称 | 单位 | 对应活动数据 |
| --- | --- | --- | --- |
| `resultFactor` | 电力排放因子 | tCO₂e/MWh | 购入电量 |
| `resultFactor` | 热力排放因子 | tCO₂/GJ | 购入热力 |
| `resultFactor` | 运输排放因子 | kgCO₂e/t·km | 运输周转量 |

后端保存时应同时保存 `parameter_code`、参数名称、单位和适用对象，不能只保存一个显示名称。

### 5.3 工艺参数

| parameter_code | 页面名称 | 单位 | 是否可编辑 |
| --- | --- | --- | ---: |
| `purity` | 碳酸盐质量百分比纯度 | % | 是 |
| `co2Factor` | CO₂排放因子 | tCO₂/t碳酸盐等 | 是 |

原料消耗量来自核算清单。计算关系：`排放量 = Σ（碳酸盐消耗量 × 纯度 × CO₂排放因子）`。

### 5.4 废水参数

| parameter_code | 页面名称 | 单位 | 是否可编辑 |
| --- | --- | --- | ---: |
| `bo` | 甲烷最大生产能力 Bo | kg CH₄/kg COD | 是 |
| `mcf` | 甲烷修正因子 MCF | —或% | 是 |
| `gwp` | CH₄全球变暖潜势（GWP100） | GWP标准单位 | 否/从GWP字典匹配 |

COD去除量、污泥清除COD量等属于核算期数据，不得作为废水因子参数返回。

### 5.5 逸散型

| parameter_code | 页面名称 | 取值方式 | 单位 |
| --- | --- | --- | --- |
| `fugitiveRate` | 设备/物质常规逸散率 | 从逸散系数字典选择 | % |
| `fugitiveGwp` | 对应物质GWP100 | 从GWP字典选择 | kgCO₂e/kg |

填充量、补充量、回收量和泄漏量由核算清单录入。逸散型计算关系：`逸散量 = 活动数据 × 逸散率`，`CO₂e = 逸散量 × GWP100`。

## 6. 来源类型字典

来源类型分为“因子来源”和“参数来源”。参数来源可以逐行不同，因子来源是整个企业因子的来源说明。

| code | 页面名称 | 证明材料 | 页面含义 |
| --- | --- | ---: | --- |
| `officialDefault` | 官方缺省值 | 不要求 | 官方标准、主管部门或平台发布的默认值 |
| `enterpriseMeasured` | 企业实测 | 要求 | 企业检测、计量或现场测定的可复用参数 |
| `supplierData` | 供应商数据 | 要求 | 供应商提供的可复用产品/设备参数 |
| `methodConstant` | 方法学常数 | 不要求 | 44/12、GWP等系统维护的固定参数 |

当前新增弹窗展示“官方缺省值、企业实测、供应商数据”。“方法学常数”由系统参数模板自动生成，不允许修改。

以下内容不作为当前新增弹窗的来源选项：企业估算值、系统计算值。估算依据和计算结果应回到活动数据或核算清单维护。

## 10. 材料状态、审核状态和有效状态

这三个状态必须分开维护，不能合并成一个“状态”。

### 9.1 材料状态

| code | 页面名称 | 含义 |
| --- | --- | --- |
| `NOT_REQUIRED` | 无需上传 | 官方缺省值或方法学常数不要求材料 |
| `PENDING` | 待补充 | 企业实测/供应商数据需要材料，但当前没有材料 |
| `UPLOADED` | 已上传（N份） | 已关联一份或多份证明材料 |

企业实测和供应商数据没有材料时，可以保存草稿，但不能作为正式可用因子。

### 9.2 审核状态

| code | 页面名称 | 含义 |
| --- | --- | --- |
| `PENDING_REVIEW` | 待审核 | 已保存，尚未完成企业内部审核 |
| `APPROVED` | 已审核 | 已完成企业内部审核 |

审核状态不代表第三方核查或认证结论。

### 9.3 有效状态

| code | 页面名称 | 含义 |
| --- | --- | --- |
| `CURRENT` | 当前有效 | 当前适用，可以参与新核算清单匹配 |
| `REPLACED` | 已被替代 | 已有新版本替代，只供历史追溯 |
| `DISABLED` | 已停用 | 暂不允许业务使用 |

## 11. 可选用状态和不可选原因

“可选用”是系统根据多个条件计算出的结果，不建议让用户手工维护。

### 10.1 可选用条件

因子同时满足以下条件时，返回“可选用”：

1. 因子类型允许普通因子使用；
2. 有效状态为“当前有效”；
3. 审核状态为“已审核”；
4. 必填参数完整；
5. 单位与当前活动数据兼容；
6. 气体、排放源类型、适用对象和适用年度匹配；
7. 需要证明材料时，材料状态不是“待补充”。

### 10.2 不可选原因字典

| code | 页面提示 |
| --- | --- |
| `TYPE_NOT_SELECTABLE` | 当前因子类型不能作为普通因子使用 |
| `NOT_CURRENT` | 因子已被替代或已停用 |
| `PENDING_REVIEW` | 因子尚未审核 |
| `PARAMETER_INCOMPLETE` | 必填参数不完整 |
| `UNIT_NOT_MATCHED` | 因子单位与活动数据单位不匹配 |
| `GAS_NOT_MATCHED` | 温室气体类型不匹配 |
| `SCOPE_NOT_MATCHED` | 排放源或适用对象不匹配 |
| `YEAR_NOT_MATCHED` | 适用年度不匹配 |
| `EVIDENCE_PENDING` | 证明材料待补充 |

页面应展示不可选原因，不能只返回“没有可用因子”。

## 12. 页面操作状态

| 操作 | 普通企业因子 | 公共因子/方法学常数 | 已被正式清单引用的版本 |
| --- | --- | --- | --- |
| 查看 | 可以 | 可以 | 可以 |
| 编辑 | 可以，建议生成新版本 | 不允许覆盖公共版本 | 不允许直接覆盖 |
| 选择到核算清单 | 满足可选条件时可以 | 满足可选条件时可以 | 历史快照可读取，新清单不可选择 |
| 删除 | 点击后先弹窗确认 | 后端按权限限制 | 不允许物理删除 |
| 停用/替代 | 按权限执行 | 按公共数据管理权限执行 | 应停用或创建替代版本 |

### 11.1 删除确认弹窗

点击列表中的“删除”后，先展示确认弹窗，至少显示：

- 因子名称；
- 数据来源；
- 当前版本/适用年度；
- 删除后的影响说明。

点击“取消”或关闭弹窗不改变数据；点击“确认删除”后才执行删除或停用请求。是否允许物理删除必须由后端根据权限和引用关系再次判断，不能只依赖前端弹窗。

| 因子来源类型字典 | 是 | 维护企业因子整体来源 |
| 温室气体类型字典 | 是 | 维护气体名称和编码 |

## 14. 对接时需要确认的原则

1. 页面显示名称可以调整，但编码一旦投入使用不要随意修改。
2. 字典的“显示名称”和“业务含义”分开保存，不能让后端根据中文名称判断业务逻辑。
3. 参数模板决定参数行，前端不能自行增加参数，后端也不能把活动数据当成参数保存。
4. GWP和逸散率必须保存字典关联关系，同时保存因子版本使用时的数值快照。
5. 材料状态、审核状态、有效状态和可选状态必须分别返回。
6. 物料平衡、回收/销毁和CEMS不进入普通新增因子下拉框。
7. 已被正式核算清单引用的因子版本必须保留，历史结果不能因为字典或因子后续变化而改变。
8. 删除按钮必须先弹确认；最终是否可以删除由后端权限和引用关系决定。
