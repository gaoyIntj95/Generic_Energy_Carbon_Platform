# 交互矩阵审计

| 范围 | 用户操作 | 页面变化/结果 | 反馈或后续关系 |
|---|---|---|---|
| 全局导航 | 点击一级/二级菜单 | 切换当前页面、更新激活态和面包屑 | 数据管理、能源监测、碳核算原型部分页面可切换；未绑定项需确认 |
| 数据管理 | 新增/编辑/删除用能单元、能源品种、能源消费、成本、运营数据、设备 | 打开居中弹窗；保存后刷新对应表格；删除直接移除模拟数据 | 下游能耗分析、碳核算是否实时同步未在原型外确认 |
| 数据管理 | 切换能源消费/能源成本/特殊能源关系 Tab | 同一页面内容替换 | 特殊能源关系引用已有能源数据，不重复填报 |
| 数据管理 | 选择能源消费层级 Tab | 限定新增数据的归属范围 | 原型明确防止不同层级混选 |
| 数据管理 | 按月填报/仅填年度值 | 表单切换月度输入或年度输入 | 月度值自动汇总年度值 |
| 数据管理 | 展开月度明细 | 表格行展开 1—12 月明细 | 可编辑月度数据 |
| 数据管理 | 查看引用/特殊关系 | 展开关系引用信息或打开编辑弹窗 | 关系由能源消费及特殊关系数据共同形成 |
| 能源监测 | 查询/重置/导出 | 更新结果表、图表或下载明细 | 导出字段、文件格式和权限未确认 |
| 能源监测 | 能效对标点击指标/查看计算口径 | 展示指标趋势、当前值、目标值、偏差率和口径说明 | 指标目标配置入口存在，但配置保存逻辑未在材料中充分说明 |
| 能源监测 | 能流图/能源平衡表 Tab | 在图形和表格视图间切换 | 一级/二级展示层级改变图和明细；节点/流向可查看来源或关系 |
| 能效平衡 | 点击平衡图节点、TOP5、清单“查看详情” | 打开右侧平衡详情抽屉 | 展示输入、终端利用、回收利用、偏差和能源流向 |
| 能效平衡 | AI 诊断/AI 建议链接 | 更新提示或打开 AI 分析抽屉 | “生成优化方案”按钮的落地形式未确认 |
| 预算管理 | 切换能源预算/碳排放预算 Tab | KPI、趋势图、执行表和 AI 建议切换单位与数据 | 预算配置弹窗会影响目标及预测数据，但持久化规则未确认 |
| 预算管理 | 点击预算执行表行 | 打开预算执行详情抽屉 | 展示目标、累计、预计全年、偏差和说明 |
| 碳资产 | 录入碳资产/新周期配额测算 | 打开对应弹窗 | 弹窗字段、测算公式和附件规则未完整呈现 |
| 碳资产 | 点击资产台账操作、查看测算说明 | 打开资产详情抽屉或测算说明 | 可查看凭证；编辑/上传行为需确认 |
| 碳核算 | 新建任务/核算设置 | 打开任务或设置弹窗 | 保存后更新行业方法、核算范围及清单；示例中切换行业会增加行业扩展组 |
| 碳核算 | 新增/查看/补充/编辑排放源 | 新增弹窗或右侧详情抽屉 | 编辑活动数据后更新排放量状态；系统识别源不可直接删除，可标记不适用 |
| 碳核算 | 排放源更多菜单 | 显示上下文菜单 | 支持删除、复制、标记不适用；自动识别记录有删除限制 |
| 碳核查支撑 | 切换基础材料/排放源支撑材料 Tab | 表格切换，说明文本同步变化 | 排放源支撑清单由碳核算清单自动生成，活动数据及来源只读 |
| 碳核查支撑 | 查看/材料管理 | 打开详情抽屉或材料管理抽屉 | 上传文件后更新材料数量和状态；支持 PDF、图片、Word、Excel 的声明需确认实际限制 |
| 碳核算 | 点击“前往核查支撑” | 关闭当前抽屉并跳转支撑页面 | 形成碳核算清单 → 核查支撑的明确跨页关系 |
| 碳因子库 | 切换全部/默认/实测/停用 Tab | 过滤因子表 | 查询条件与 Tab 条件叠加 |
| 碳因子库 | 查看/编辑/启用停用/复制因子 | 查看打开详情抽屉，编辑打开弹窗 | 保存后刷新；复制生成副本；停用状态影响 Tab 过滤 |
| 碳因子库 | 批量导入 | 打开导入弹窗并选择文件 | 原型标注支持 `.xlsx/.csv`、单次不超过 10MB，但导入校验和失败处理未确认 |

## 弹窗、抽屉、Tab 关系

- 同一时刻使用统一遮罩层；点击遮罩会关闭弹窗/抽屉和上下文菜单。
- 列表行的“查看”通常进入右侧抽屉；“新增/编辑/设置/导入”通常进入居中弹窗。
- 抽屉可继续跳转到另一个抽屉（支撑材料详情 → 材料管理），或关闭后跳转到其他页面（排放源详情 → 核查支撑）。
- 数据管理的能源数据三个 Tab、碳核查支撑两个 Tab、碳因子库四个 Tab、预算管理两个 Tab、能流分析两个视图 Tab 均属于页面内状态切换，不是独立路由。
