# 页面清单与页面元素审计

> 审计范围：`reference/html/` 下 4 个 HTML 原型、`docs/` 下现有业务说明、根目录 `AGENTS.md`。
> `reference/screenshots/` 四个目录当前均为空，因此本文件无法引用效果图中的独立信息。

## 1. 菜单与页面

### 数据管理

动力中心下二级公辅用能单元的名称由用户填写。一期表单仅配置一条能源转换关系（一种投入、一种产出），不提供添加、删除关系入口，暂不支持热电联产等多关系配置。“常用关系 / 自定义”通过独立按钮切换；常用关系按产出能源分组，选项仅显示“投入 → 产出”；自定义模式隐藏常用关系下拉，仅显示投入、产出能源品种选择，不支持自由文本新增品种。切换方式保留已填能源；自定义组合不属于常用关系时，切回常用模式需重新选择后才能保存。所属单元、层级与默认类型合并为一行，修改类型按需展开；备注默认折叠，编辑已有备注时展开。按当前年度能源品种 ID 保存，校验必填、品种有效及投入产出不能相同。保留原有数组存储结构；旧多关系记录不自动删减，当前表单拦截编辑保存。关系配置不自动生成计量记录或重复计算投入，实际数量仍由能源台账维护。详细规则收入字段旁帮助提示。蒸汽统一使用“蒸汽”品种，余热回收来源由投入能源及转换记录保留。

一级菜单：数据管理。

二级菜单及页面：

1. 用能单元：用能单元管理
2. 能源品种：能源品种管理
3. 能源数据：能源消费、能源成本、特殊能源关系（同一页面内 Tab）
4. 运营数据：运营数据管理
5. 重点设备：重点设备管理

### 能源监测与分析

一级菜单：能源监测与分析。

二级菜单及页面：能耗查询、能耗强度指标、能效对标、能流分析。

原型同时展示了“首页概览”“数据管理”“碳管理”“系统管理”等全局导航，其中数据管理下含上述 5 项，碳管理下出现“碳排放核算”“碳足迹核算”，系统管理下出现“组织管理”“权限管理”。这些导航项在本 HTML 中并非全部有完整页面实现。

### 碳排放核算与合规

一级菜单：碳排放核算与合规。

二级菜单及页面：碳排放预览、碳核算清单、碳核查支撑、碳排报告、碳因子库。另有“供应商数据采集”“碳足迹交付管理”导航项，但未绑定页面切换实现。

### 能碳资产运营与策略

一级菜单：能碳资产运营与策略。

二级菜单及页面：能源平衡与优化、用能分析与策略推荐、用能与碳排放预算管理、碳资产管理。

## 2. 页面元素

### 数据管理

所有页面顶部时间筛选仅保留年度并置于其他条件之前；设备产出、能源消费、能源成本、转换与外供、运营数据的“查看”统一在当前行下展开 1—12 月明细，“查看”为只读；“编辑”统一打开弹窗维护全年数据，不重复显示每月编辑按钮，弹窗底部只保留一组保存、取消；保存或取消后关闭弹窗，列表保持原有展开状态；年度静态指标保留年度值且不摊分。所有页面按年度独立维护，关联选项、删除引用检查与编辑读取均使用当前年度；模块内导航保留年度，重置筛选不切换年度。已有演示年度分别初始化档案，后续修改互不影响。

| 页面 | 筛选项 | 摘要/图表 | 表格 | 按钮与操作 |
|---|---|---|---|---|
| 用能单元管理 | 维护年度、关键字、单元类型 | 无摘要卡；一级/二级层级展开 | 用能单元、层级、单元类型、操作 | 新增一级用能单元、添加下级、编辑、删除 |
| 能源品种管理 | 维护年度、关键字、分析类别 | 无摘要卡 | 能源品种、计量单位、折标系数、折标单位、操作 | 新增能源品种、编辑、删除 |
| 能源消费 | 年度、分析类别、关键字；一级/二级/其他层级 Tab | 月度数据展开、年度合计、数据进度 | 归属范围/层级、分析类别、能源品种、单位、数据进度、年度合计、操作 | 新增能源消费、按月填报、仅填年度值、月度明细、编辑、删除 |
| 能源成本 | 年度、能源品种 | 查看展开 1—12 月成本、年度自动汇总 | 能源品种、年度合计、操作 | 新增成本数据、查看、编辑、删除 |
| 能源转换与外供 | 年度、关键字 | 查看展开全年月度明细；编辑通过弹窗维护全年数据 | 均匀分布用能单元、能源关系、产出能源、年度能源投入、年度产出、年度损失、操作；外供展示年度数量 | 查看、编辑、删除；主表删除整年需确认；单月清空输入后保存；登记外供及切换来源 |
| 运营数据 | 年度、指标类别、关键字 | 月度数据可展开、年度值 | 归属范围、指标类别、指标名称、单位、年度值、操作 | 新增运营数据、查看、编辑、删除 |
| 重点设备 | 维护年度、关键字、所属用能单元、主要能源品种 | 无摘要卡 | 所属用能单元、设备名称、设备类型、主要能源品种、备注、操作 | 新增重点设备、编辑、删除 |
| 设备产出数据 | 年度、关键字；可从指标带入设备和年度 | 有产出数据的设备优先；无数据设备标记待录入 | 重点设备、所属用能单元、设备产出口径、数据进度、年度值、操作 | 继承全部重点设备、录入、查看、编辑、删除；删除需确认，仅清除所选年度产出（月度及年度值），保留设备档案和其他年度；用于设备能耗指标，不关联能流 |

### 能源监测与分析

| 页面 | 筛选项 | 摘要/图表 | 表格 | 按钮与操作 |
|---|---|---|---|---|
| 能耗查询 | 月度/年度、年度、分析类别、用能单元、月份 | 查询结果摘要及月度/年度能耗结果 | 能耗明细/台账 | 查询、重置、导出明细/导出台账、查看 |
| 能耗强度指标 | 年度、月份、分析对象/用能单元 | 指标卡、指标趋势图，支持越低越好/越高越好 | 指标明细 | 查询、重置、查看计算口径、指标目标配置 |
