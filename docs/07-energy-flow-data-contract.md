# 能流分析一期数据契约

本文档用于约束“数据管理—能源数据”到“能源监测与分析—能流分析”的一期数据流转，不扩展二级用能单元、设备级或多对象组合能力。

## 1. 一期数据映射

能流图中的“厂内可供分配能源”是外购能源扣除转换投入、加上内部转换产出后，在企业内部形成的可分配能源量，不等同于实际使用量。实际使用应通过后续一级/二级用能单元的能源分配或利用数据查看。

| 数据管理记录 | 能流分析含义 | 一期规则 |
|---|---|---|
| 企业级能源消费记录 | 能源输入 | 纳入企业边界输入，不再向下追溯分配来源 |
| 一级用能单元能源消费记录 | 一级能源分配 | 作为一级用能单元的分配量，用于能流图、平衡表和 TOP5 |
| 能源转换与输出记录 | 能源转换、内部利用、外部输出 | 通过 `inputEnergyRecordId` 关联上游能源记录，避免重复计入企业输入 |
| 二级用能单元或设备记录 | 二级能源利用/设备数据 | 一期能流分析不纳入 |

## 2. 时间规则

- 年度分析使用年度值；没有年度补录值时汇总已填报的月度值。
- 月度分析只使用当前月份已填报的月度值。
- 年度值不得自动平均或按比例分摊到月份。
- 月度数据缺失时，页面展示数据质量提示，不将年度值静默当作当前月份数据。
- 月度转换结果沿用已有转换记录与上游月度能源数据的期间比例；上游仅有年度值时不生成虚假的月度流量，并通过数据质量提示说明。

## 3. 统一计算口径

页面主分析口径为折标量（tce）。流向明细和追溯信息同时展示原始实物量、原始单位、折标量和折标系数。

一级能源平衡关系为：

```text
外部输入 + 内部回收 + 转换产出
= 转换投入 + 一级内部配置 + 外部输出 + 未分配量
```

未分配量是管理口径下尚未归属到一级用能单元的差额，不等同于物理损失。

能流图、KPI、TOP5、平衡表和流向明细必须使用同一分析数据集。
