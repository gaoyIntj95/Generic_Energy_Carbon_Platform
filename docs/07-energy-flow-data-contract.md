# 能流分析一期数据契约

2026-09-09：维护交互与权威来源以 [能源转换与流向简化方案](12-energy-flow-maintenance.md) 为准。转换产出在能源转换与外供按用能单元独立维护，不引用设备产出；所有转换记录均不按年度比例生成缺失月份。

本文档用于约束“数据管理—能源数据”到“能源监测与分析—能流分析”的一期数据流转，不扩展二级用能单元、设备级或多对象组合能力。用能单元主数据虽然支持二级归属，但由于二级能源数据可能不完整，一期能流不汇总二级能源消费记录。

## 1. 一期数据映射

能流图的第一列“企业边界输入”只渲染真正跨越企业边界的能源消费记录。生产过程中产生的余热、余压等内部回收量保留在平衡数据中，但不生成企业边界输入节点；锅炉、空压等设施归入“能源转换”，余热发电与余热回收归入“能源回收与循环利用”，并展示具体来源及回流产出。

厂内能源池按来源区分名称：锅炉产出的蒸汽显示为“锅炉蒸汽”，余热回收系统产出的能源显示为“回收蒸汽”。同一能源品种的外购输入和转换产出仍按既有数据契约汇总计算，不能据此推断具体设备到车间的物理供能路径。

能流图中的“厂内可供分配能源”是外购能源扣除转换投入、加上内部转换产出后，在企业内部形成的可分配能源量，不等同于实际使用量。实际使用应通过后续一级/二级用能单元的能源分配或利用数据查看。

| 数据管理记录 | 能流分析含义 | 一期规则 |
|---|---|---|
| 企业级能源消费记录 | 能源输入 | 纳入企业边界输入，不再向下追溯分配来源 |
| 一级用能单元能源消费记录 | 一级能源分配 | 作为一级用能单元的分配量，用于能流图、平衡表和 TOP5 |
| 能源转换与输出记录 | 能源转换、能源回收、内部利用、外部输出 | 通过 `inputEnergyRecordId` 关联上游能源记录，使用 `conversionEnergyUnitId` 标识设施，使用 `outputTargetEnergyUnitId` 标识内部产出去向，回收产出通过回流关系返回厂内能源池，避免重复计入企业输入 |
| 二级用能单元投入记录 | 转换与回收能源投入 | 六套系统各自维护同年度二级投入，能源消费页可查。余热、余压保留内部回收属性，不计企业外购能源；转换关系引用后进入该系统投入，不自动汇总到一级分配量。无引用记录时不使用历史缓存数量 |
| 设备能源消费与设备产出 | 设备指标数据 | 不作为用能单元转换投入或产出，不自动汇总到能流 |

## 2. 时间规则

- 能流年度分析覆盖所选年度 1—12 月，不再固定截至 6 月。能源消费投入优先使用已补录年度台账值，没有年度补录值时汇总全年已填报月度值；与能源转换与外供的年度投入口径一致。
- 转换产出、外供和损失按全年已填报月份累计；有月度数组时以有效月份合计为准，避免旧年度合计与月度记录不一致。仅有年度值、无月度数组的历史记录沿用年度值。外供仍逐月核验，待核验月份不进入有效流量。
- 月度分析只使用当前月份已填报的月度值。
- 年度值不得自动平均或按比例分摊到月份。
- 月度数据缺失时，页面展示数据质量提示，不将年度值静默当作当前月份数据。
- 月度投入取来源记录所选月已填报数量；产出、外供和损失分别取本页所选月数量。仅有年度值时不生成月度流量；缺失标识优先于残留数值，明确填写零仍为有效填报。
- 转换记录的内部供能量大于 0 时必须绑定一级或二级用能单元；企业外部供能量绑定接收方，不绑定内部去向。

## 3. 统一计算口径

页面仅保留“能流图”和“能源平衡表”两个 Tab，主分析口径为折标量（tce）。取消流向明细表、明细筛选、明细导出及关联跳转入口。

一级能源平衡关系为：

```text
来源合计 = 外部输入 + 过程回收 + 转换产出
已登记去向合计 = 转换投入 + 一级用能单元消耗 + 对外输出 + 已确认转换损失
收支差额 = 来源合计 − 已登记去向合计
```

未分配量是管理口径下尚未归属到一级用能单元的差额，不等同于物理损失。

能流图、KPI和平衡表必须使用同一分析数据集。

2026-09-09 能流图布局补充：回收来源连线优先按转换关系中保留的实际产生来源关联一级用能单元，投入数量则读取回收系统自己的二级台账，回收产出沿底部虚线通道返回能源池。企业边界输出作为能源池的支线，当前分析期间存在有效输出时自动显示，不存在时隐藏图例、节点和区域并收起占位，不提供显示开关。图中的能源池展示外供前可供量（厂内净可供量加转换外供量），与外供、分配及未分配流线核对；数据集的厂内净可供字段保持原有含义，页面平衡表按完整来源与已登记去向列示。

典型工业场景补充：能源转换包含“原煤 → 自备发电机组 → 厂内电力”；能源回收包含“动力中心余压 → 余压回收系统 → 厂内压缩空气”。空压系统节点同时标明其下属的 1#、2# 螺杆空压机，系统汇总量仍作为能流计算口径，避免把两台设备重复累计。

## 4. 节点聚焦关系

点击节点后，数据层分别追溯上游和下游，仅将实际遍历到的连线及端点标记为关联范围。能流图始终以完整节点和连线计算布局，点击仅突出关联关系、淡化无关关系，不移动节点、不收起分栏、不改变图尺寸或流量线宽。共享某个节点不代表其全部支路相关。非当前选中的用能单元作为追溯边界，避免将该单元不同能源品种的消费和回收推断为专属路径；下游回收产出返回能源池后停止继续分配。

能源平衡表与图中高亮范围使用同一关联连线集合。再次点击当前节点、清除选择或重新查询可解除聚焦。卡片和源记录保持本期原始汇总量，不按链路估算设备到车间的供能比例。顶部指标保留全厂口径。能源平衡表随节点聚焦切换为当前链路逐节点收支核对；未展开来源或去向、边界和用能单元不判定损失或超分配。解除聚焦时恢复企业能源平衡表。

选中节点时，能源平衡表使用当前关联连线按端点累计流入、流出；未选节点时展示全厂能源平衡表。平衡表导出遵循当前期间及所选范围。底层流向记录及换算数据保留供共享计算使用，不再提供独立明细视图。

## 5. 能源平衡表展示与导出

- 每行一个能源品种；列按“能源来源、已登记去向、收支差额”分组。来源分为外部输入、过程回收、转换产出，去向分为转换投入、用能单元消耗、对外输出、已确认损失，分别列合计。
- “过程回收”对应 `internalRecoveryStandardAmount`，指作为回收装置投入的余热、余压等；“转换产出”对应 `conversionOutputStandardAmount`，包含发电、供汽、空压及回收装置的产出。保留“回收蒸汽”等能源品种及独立台账，不按名称合并，也不将品种名称当成来源项目。
- 正收支差额表示待分配，负差额表示超分配；不把未分配列入实际去向，也不通过添加超分配补差使结果强制闭合。底层能流与顶部指标口径不变。
- 按能源品种逐项提示，正负差额不能相互抵消后判定全部平衡。差额不是物理损失；已确认损失只取已登记值，未填报不代表确认零损失。
- 显示统一保留两位小数，差额提示按同一显示精度判断，避免 `-0.00` 及红色 `0.00`。此精度不是计量允差。合计先汇总未舍入值，再格式化。
- 页面和 CSV 共用收支分项及差额计算，导出包含期间、范围、单位、每种能源核对结果和分项合计。分项合计含企业内部转换与回收流转，不能解读为企业外购量或综合能耗。页面零值用“—”，CSV 保留数值零。
- 空数据不显示“收支相符”；数据质量提示在平衡表继续展示。节点聚焦时沿用关联链路逐节点收支表，不替换为全厂汇总。

- 平衡表不再展示与差额列重复的顶部核对摘要；差额数值与状态同行展示。口径说明在表格下方常驻，按过程回收、转换产出、已确认损失分栏，不提供折叠开关。
