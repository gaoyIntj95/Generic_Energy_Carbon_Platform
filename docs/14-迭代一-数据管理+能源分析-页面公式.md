# 数据管理与能源监测分析页面公式口径

> 本文面向测试同事，按当前页面实现整理。页面实现优先，PRD 仅用于补充业务背景和标注差异。
>
> 覆盖页面：能源监测与分析 4 页，以及数据管理 8 页。能耗查询页的年度/月度明细公式已在 docs/13-numerical-calculation-caliber.md 第 1 节展开，本文不重复整段内容。

## 1. 统一约定

### 1.1 年度/月度取值

能源消费记录只统计页面上标记为“已上报”或已填写的有效月份；未上报月份不参与已上报月份合计。

能源记录的年度实物量：

    月度有效合计 = Σ 有效月份能源实物量
    年度补录值大于 0 时，年度实物量 = 年度补录值；否则 = 月度有效合计

年度补录值是补充值，不与月度合计相加；缺失月份不根据年度值自动摊分。

运营指标的年度值：

    月度模式且 12 个月完整：年度值 = Σ 月度值
    月度模式不完整且年度补录 > 0：年度值 = 年度补录
    月度模式不完整且无年度补录：年度值 = 已填写月度值之和
    年度单值模式：年度值 = 年度单值

成本台账使用同样的年度补录优先规则：

    月度成本合计 = Σ 月度成本
    年度补录成本大于 0 时，年度成本 = 年度补录成本；否则 = 月度成本合计

### 1.2 折标

原系数单位为 kgce/ 时，分析层规范化系数为：

    规范化系数 = 原折标系数 ÷ 1000

原系数单位为 tce/ 时不再除以 1000。

所有能源分析使用：

    折标量（tce） = 实物量 × 规范化折标系数

能流链路需要恢复原始实物量时，仅对仍以 kgce/原始单位维护的系数做反向单位换算：

    原始实物量 = 折标量（tce）× 1000 ÷ 原折标系数（kgce/原始单位）

这里的 ×1000 仅表示 tce→kgce 的单位换算，不属于单位产出能耗等强度指标公式；若原折标系数已是 tce/原始单位，则不乘 1000。

页面展示舍入不参与后续汇总。不同页面的展示精度以页面实际显示规则为准，不能用显示值反推原始计算值。

### 1.3 无法计算

缺少有效折标系数、分母为空、分母小于等于 0、月度能源未上报或必要的 12 个月数据不完整时，指标通常不生成，页面显示“—”。原型中的示例数据或固定状态以页面实际展示为准。

### 1.4 默认分析期间

默认年度不再写死为 2026 年，取能源消费台账中存在的最新年度。

最新年度的默认月份取该年度企业级能源消费记录从 1 月开始连续已上报的最后月份；遇到首个未上报月份即停止，不把年度值平均摊到月份。没有企业级月度记录时，当前年度回退到系统当前月份，历史年度按 12 月处理。

因此页面的默认月份、年度趋势标题、明细期间标题、能流分析月份和各分析页年度选项都由数据期间动态生成，不再固定为某个年度或月份。

## 2. 能源监测与分析

本节覆盖页面：能耗查询、能耗指标、能效对标、能源流向分析。测试以页面筛选条件、表格、卡片、图表、弹窗和页面提示为准，不需要依据源码路径定位数据。

### 2.1 能耗指标

入口：/energy-analysis/intensity。

#### 2.1.1 公共公式

企业或用能单元综合能耗：

    综合能耗（tce） = Σ（能源年度实物量 × 规范化折标系数）

月度能源分子：

    月度折标量 = 月度实物量 × 规范化折标系数

对比变化：

    变化率 =（当前值 − 对比值）÷ 对比值 × 100%

当前页面对比值为 0 或不存在时显示 0，不区分真实 0% 与无对比基数。

#### 2.1.2 全厂指标

全厂分子只读取企业级能源消费记录，不把一级、二级用能单元记录再次加到全厂。

    单位产品综合能耗 = 综合能耗（tce）÷ 企业产品产量
    单位产值综合能耗 = 综合能耗（tce）÷ 工业总产值

页面当前的单位增加值综合能耗不可计算：

    单位增加值综合能耗 = 不可计算，页面显示“—”

PRD 期望的业务公式是：

    单位增加值综合能耗 = 综合能耗（tce）÷ 工业增加值

因此测试当前页面时，单位增加值指标应验收为“—”，不能用工业总产值代替工业增加值。

#### 2.1.3 生产类用能单元

    单位产品综合能耗 = 用能单元综合能耗（tce）÷ 该单元产品产量

产品产量使用“运营数据”页面中的产品产量年度值。产品产量、能源分子缺失或产品产量小于等于 0 时不生成结果。

#### 2.1.4 非生产类用能单元

| 指标 | 页面当前公式 | 分母 |
| --- | --- | --- |
| 单位供气电耗 | 空压系统电力消费量（kWh）÷ 供气量（Nm³） | 动力中心有效供能量 |
| 余热发电转换效率 | 发电量折标值 ÷ 回收余热折标值 × 100% | 回收余热折标量 |
| 单位蒸汽综合能耗 | 综合能耗（tce）÷ 蒸汽产量（t） | 蒸汽产量 |
| 单位供能量综合能耗 | 综合能耗（tce）÷ 动力中心供能量（GJ） | 动力中心有效供能量 |
| 单位建筑面积综合能耗 | 综合能耗（tce）÷ 建筑面积（m²） | 运营数据中的建筑面积年度值 |
| 单位物流作业量综合能耗 | 综合能耗（tce）÷ 物流作业量 | 物流运营指标 |
| 单位运行能耗 | 综合能耗（tce）÷ 配置的运营量 | 当前单元绑定的运营分母 |

说明：`单位供气电耗`是电力实物消耗指标，保留 `kWh/Nm³`；它不等同于设备单位产出综合能耗，后者统一使用 `tce/原始分母单位`。

动力中心供能量换算为 GJ：

    GJ 原值：GJ = 原值
    MJ：GJ = 原值 ÷ 1000
    kWh：GJ = 原值 × 0.0036
    MWh：GJ = 原值 × 3.6

分母为空、为 0、能源月份未上报或转换输入/输出不完整时，不生成指标。

#### 2.1.5 产品对象

当前产品对象页面实际显示口径是：

    产品对象综合能耗 = 关联生产用能单元的综合能耗（tce）

该结果不是单位产品综合能耗，当前产品对象页面不按产品产量再次除算。

页面另有产品汇总补充口径：

    产品汇总单位产品能耗
      = 企业综合能耗（tce）÷ 所选产品总产量

但该辅助结果不是当前产品对象列表的主展示结果。PRD要求的产品公式为：

    单位产品综合能耗
      = 产品分配后的综合能耗（tce）÷ 产品年度产量

多产品分配配置的校验公式：

    同一生产用能单元下有效产品分配比例之和 = 100%

每个比例必须大于 0 且不超过 100%；单产品自动按 100%。未配置完整或合计不等于 100% 时，不生成单位产品能耗。

#### 2.1.6 重点设备指标

设备指标模板计算：

    设备指标 = 分子 ÷ 分母 × 调整系数

分子规则：

- 电力：设备年度电力实物量 × 规范化折标系数，分子单位为 tce；
- 其他能源：设备年度能源实物量 × 规范化折标系数，分子单位为 tce；
- 分母：设备产出数据或转换产出数据。

因此，设备单位产出能耗统一为：

    单位产出能耗（tce/原始分母单位）
      = 设备折标综合能耗（tce）÷ 设备产出量

因此，电力和非电力设备的单位产出能耗均为 `tce/原始分母单位`；电力折标使用能源品种的规范化系数，不额外套用 ×1000。

当设备指标模板设置为“百分比调整”时，调整系数取模板配置值；其他计算方式的调整系数为 1。

设备月度指标：

    月度设备指标 = 月度能源分子 × 调整系数 ÷ 月度分母

月度能源未上报、分母不大于 0 或设备没有指标模板时不生成指标。设备产出数据只作为设备指标分母，不回写企业能源消费、用能单元台账或能流。

### 2.2 能效对标

入口：/energy-analysis/benchmarking。

#### 2.2.1 实际值

- 全厂、用能单元、产品：复用能耗指标页的结果；
- 重点设备：取设备能源记录年度实物量。

设备对标行的实际值为：

    设备对标实际值 = 设备能源记录年度实物量

设备对标不是设备强度指标，因此不再除以设备产出分母。

#### 2.2.2 目标差异和达标

目标值来自目标配置，页面不根据历史数据自动计算目标。

    绝对差值 = 当前值 − 目标值
    对标偏差率 =（当前值 − 目标值）÷ 目标值 × 100%

目标值小于等于 0 或未配置时，偏差率不可作为有效业务结果。

指标方向为“越低越好”时：

    当前值 ≤ 目标值：达标

指标方向为“越高越好”时：

    当前值 ≥ 目标值：达标

实际值必须有效且目标值必须大于 0，才进入正常达标判断。

#### 2.2.3 月度和季度趋势

仅当月度实际完整、月度目标恰好有 12 个月且目标已配置时，生成月度偏差：

    月度偏差率 =（月度实际值 − 月度目标值）÷ 月度目标值 × 100%

季度聚合：

- 设备：季度值 = 季度内月度值之和；
- 非设备指标：季度值 = 季度内月度值平均值；
- 年度：使用年度实际值和年度目标值。

有月度目标时，趋势目标线使用每月目标；否则把年度目标重复到趋势点。月度数据不完整时，趋势退化为年度实际值。

#### 2.2.4 产品分配补充计算口径（当前页面主展示未采用）

原型中保留一套产品分配计算：

    产品分配能源（tce） = Σ（能源记录折标量 × 产品分配比例）
    单位产品综合能耗 = 产品分配能源（tce）÷ 产品年度产量
    月度单位产品能耗
      = Σ（月度能源折标量 × 分配比例）
        ÷ Σ（月度产品产量）

当前页面主展示以能耗指标结果和设备对标结果为主。产品分配公式属于补充口径，不要误认为当前页面主展示公式。

### 2.3 能流分析

入口：/energy-analysis/flow-analysis。

页面固定使用 tce 作为展示口径，默认分析全厂管理口径。

#### 2.3.1 时段取数

年度月度记录：

    年度实物量 = Σ 有效月份实物量

年度单值或年度补录记录使用年度值；月度分析中年度单值记录不参与，未上报月份取 0 或不生成有效数据。

    折标量（tce） = 实物量 × 规范化折标系数

#### 2.3.2 转换关系

    转换投入折标量 = 转换投入实物量 × 投入能源折标系数
    转换产出折标量 = 转换产出实物量 × 产出能源折标系数
    内部使用折标量 = 内部使用实物量 × 产出能源折标系数
    转换外供折标量 = Σ关联外供记录折标量
    已确认损失折标量 = 损失实物量 × 产出能源折标系数

转换产出质量校验：

    转换产出 = 内部使用 + 外供 + 已确认损失

页面按极小数值误差判断投入、产出、内部使用、外供和损失是否相等。校验失败时标记转换产出分配异常。

转换折标差额：

    转换折标差额 = Σ |转换投入折标量 − 转换产出折标量|

该差额不等同于已确认转换损失。

#### 2.3.3 企业输入和可供分配

    能源输入量 = 外部输入量 + 内部回收量

逐能源品种：

    可供分配量
      = 外部输入量 + 内部回收量
        − 转换投入量 + 转换产出内部使用量

    一级分配量 = Σ一级用能单元能源消费量
    直接外部输出量 = 企业直接外供量 + 转换外供量

    未分配量
      = MAX（可供分配量 − 一级分配量 − 直接外部输出量，0）

    超分配量
      = MAX（一级分配量 + 直接外部输出量 − 可供分配量，0）

状态阈值：

- 差额小于 -0.01：超分配；
- 差额大于 0.01：未分配；
- 其余：已分配。

#### 2.3.4 二级利用

    二级利用量 = Σ二级用能单元能源消费量
    二级待分配量 = MAX（一级分配量 − 二级利用量，0）
    二级超分配量 = MAX（二级利用量 − 一级分配量，0）

    一级分配率 = 一级分配量 ÷ 可供分配量 × 100%
    二级归集率 = 二级利用量 ÷ 一级分配量 × 100%

分母为 0 时不生成有效比率。二级利用超过一级分配时单独标记层级异常或超分配，不生成负值待分配量。

#### 2.3.5 页面 KPI

| KPI | 当前页面来源 |
| --- | --- |
| 能源输入量 | 外部输入折标量 + 内部回收折标量 |
| 内部分配量/内部利用量 | 一级视图取一级分配量；二级视图取二级利用量 |
| 未分配量/待分配量 | 一级视图取一级未分配量；二级视图取二级待分配量 |
| 转换损失 | Σ MAX（转换投入折标量 − 转换产出折标量，0） |

辅助口径：

    可供内部使用量
      = MAX（能源输入量 − 转换投入量 + 转换产出内部使用量，0）

    转换折标差额
      = Σ |转换投入折标量 − 转换产出折标量|

KPI 的“转换损失”是投入大于产出的折标差额；平衡表的“已确认损失”只取损失台账登记值。

#### 2.3.6 能流图和能源平衡表

能流图节点：

    流入量 = Σ登记链路中指向该节点的折标量
    流出量 = Σ登记链路中从该节点发出的折标量
    节点收支差额 = 流入量 − 流出量

边界输入、企业外供、一级分配、二级利用、未分配和待分配节点隐藏该差额；普通转换或回收节点显示差额，绝对值小于 1e-6 时显示 0。页面不推断未登记链路。

能源平衡表：

    来源合计 = 外部输入 + 内部回收 + 转换产出
    去向合计 = 转换投入 + 用能单元消耗 + 外部输出 + 已确认转换损失
    收支差额 = 来源合计 − 去向合计

差额大于 0 为待分配，小于 0 为超分配，等于 0 为收支相符；来源和去向均为 0 时为无可核对量。

已确认转换损失不使用转换折标差额，也不使用未分配/超分配抵消。

## 3. 数据管理

本节覆盖数据管理页面：能源品种、用能单元、重点设备、设备产出数据、能源消费、能源成本、能源转换回收与外供、运营数据。

### 3.1 能源品种

入口：/data-management/energy-types。

这是纯能源主数据配置页面，没有运行期派生业务公式。维护内容包括名称、类别、计量单位、折标系数、折标系数单位，以及是否可作为输入/输出/回收能源。

预置系数例如：

    电力 = 0.1229 kgce/kWh
    天然气 = 1.32836 kgce/Nm³
    原煤 = 0.7143 tce/t

这些是原型初始示例系数，不是页面动态计算结果。保存时校验名称、单位、系数、系数单位和重复名称；折标量在能源消费、能耗指标和能流分析页面计算。

删除仅执行业务引用检查，不涉及数值公式。

### 3.2 用能单元

入口：/data-management/units。

这是层级和关联配置页面，没有数值派生公式。维护一级/二级父子关系、类型、区域、状态、适用能源、产品、运营指标和设备关系。

保存父子关系不会自动把父级能源分摊给子级，也不会把子级能源自动写回父级台账。父子关系只影响后续筛选和分析范围。

### 3.3 重点设备

入口：/data-management/devices。

这是设备档案和指标配置页面，没有运行期派生数值。维护所属用能单元、主要能源、设备类型、状态、输出基础和设备指标模板。

输出基础只是设备指标的分母配置；保存设备档案不会自动产生能源消费或能流数据。设备指标公式见 2.1.6。

### 3.4 设备产出数据

入口：/data-management/device-output。

设备产出数据只维护设备指标分母。

    月度合计 = Σ已填写月度值
    月度完整 = 12 个月均为有限且非负数

年度有效值：

    月度完整或未填写年度补录：年度有效值 = 月度合计
    月度不完整且填写年度补录：年度有效值 = 年度补录

保存校验：

- 月度和年度至少有一项；
- 输入必须为有限且不小于 0；
- 年度补录存在时，年度补录必须大于等于已填写月度合计；
- 单位必填。

月度完整时按月度数据保存；月度不完整但有年度补录时按年度补录保存。不会把年度值自动摊到缺失月份。

### 3.5 能源消费

入口：/data-management/energy-data，默认能源消费 tab。

年度合计：

    月度有效合计
      = Σ 已上报月份的能源实物量

    年度补录值大于 0 时，年度展示值 = 年度补录值；否则 = 月度有效合计

未标记为已上报的月份，即使录入了数值，也不计入年度合计。

编辑校验：

    月度录入合计 = Σ（各月输入值；空值按 0）
    月度完整 = 已报月份数量 = 12

月度完整时年度补录保存为 0；不完整时保存用户输入的年度补录值。年度补录大于 0 时必须满足：

    年度补录值 ≥ 月度录入合计

页面不会把年度补录减去月度合计后自动分配给缺失月份。

页面标签阶段不是数值公式：

- 企业级：能源输入；
- 一级用能单元：能源分配；
- 二级用能单元：能源利用；
- 设备：设备用能；
- 回收记录：回收能源。

能源消费页面只显示原始能源台账和月度明细，不在本页计算 tce。

### 3.6 能源成本

入口：/data-management/energy-data?tab=costs。

    月度成本合计 = Σ 月度成本
    年度补录成本大于 0 时，年度成本展示值 = 年度补录成本；否则 = 月度成本合计

12 个月均已报告时年度补录保存为 0；月度不完整时允许年度补录；若年度补录大于 0：

    年度补录成本 ≥ 已填写月度成本合计

本页不自动摊分年度成本，不计算单位能耗成本、单位产品成本或成本折标量；成本单位按页面台账使用万元。

### 3.7 能源转换、回收与外供

入口：/data-management/energy-data?tab=recovery，页面内部还提供转换和外供维护视图。

#### 3.7.1 转换产出、损失和输入

存在月度明细时：

    有效年度产出
      = Σ 已上报月份的转换产出量

    有效年度损失
      = Σ 已上报月份的转换损失量

没有月度明细时回退到年度产出值或年度损失值。月度未报告时不作为已确认 0。

转换输入来源：

    选择年度录入或年度补录值大于 0：取年度补录值
    其他情况：取已上报月份的月度输入合计

保存月度产出/损失时：

    年度产出值 = Σ 月度产出
    年度损失值 = Σ 月度损失

月度输入全部清空时，对应年度值清空。页面不会根据投入量和效率自动推算产出。

#### 3.7.2 转换产出分配

    产出量 = 内部使用量 + 外供量 + 已确认损失量
    内部可供量 = 产出量 − 外供量 − 已确认损失量

不平衡时提示数据质量问题，不把差额静默当作损失。

#### 3.7.3 外供容量

直接外供：

    年度外供量 ≤ 关联企业级来源年度量
    每月外供量 ≤ 对应月份的企业级来源量

转换外供：

    年度外供量 ≤ 转换产出 − 内部使用 − 已确认损失
    每月外供量 ≤ 对应月份的转换产出 − 内部使用 − 已确认损失

外供年度展示值：

    有月度明细：Σ 已上报月份外供量
    无月度明细：年度外供量

外供会进入能流分析的企业边界输出或转换外供，不再重复计入能源输入。

页面验收时统一按“产出 − 内部使用 − 已确认损失”校验可外供量；如不同入口出现不同提示，应记录为页面口径不一致问题。

### 3.8 运营数据

入口：/data-management/operations。

#### 3.8.1 运营指标年度值

普通月度指标：

    月度合计 = Σ（各月运营指标值；空值按 0）
    年度展示值
      月度完整时 = 月度合计；
      月度不完整且年度补录值大于 0 时 = 年度补录值；
      否则 = 已填写月度值合计

固定年度指标（例如办公建筑面积）：

    年度展示值 = 年度单值

固定年度指标不生成月份输入，也不执行月度求和。

页面按年度、层级、用能单元、指标名称和产品范围识别同一运营指标；同时存在月度和年度单值时优先使用月度指标。该规则是数据选择，不是数值计算。

#### 3.8.2 产品产量和比例

产品产量使用“运营数据”中的产品产量指标，作为指标分母：

    单位产品综合能耗
      = 分配后的综合能耗（tce）÷ 产品年度产量

比例校验：

- 单个产品：自动 100%；
- 多个产品：每个比例大于 0，所有比例合计等于 100%；
- 校验不通过时不生成单位产品综合能耗。

运营数据页面只保存产量和分配关系，不在本页计算能源量或单位能耗。

## 4. 页面现状与 PRD 的测试差异

| 编号 | 页面当前表现 | PRD/业务期望 | 测试建议 |
| --- | --- | --- | --- |
| D-01 | 全厂只读企业级能源记录 | PRD强调企业边界和分配口径 | 同时构造企业级、一级、二级记录，确认不重复汇总 |
| D-02 | 产品对象页面当前展示关联用能单元综合能耗，不除产品产量 | PRD要求产品单位产品综合能耗 | 当前测试按页面现状验收；如按 PRD验收，应先确认产品口径是否调整 |
| D-03 | 单位增加值指标当前返回不可计算 | PRD列出单位增加值综合能耗 | 验证显示“—”，不能用产值分母替代 |
| D-04 | 对比值为 0 时变化率返回 0 | 业务上可能应显示无基数 | 区分真实 0% 和无对比基数 |
| D-05 | 外供有新旧两条容量校验路径 | 统一口径应为产出−内部使用−损失 | 分别覆盖新入口和旧 flow 入口 |
| D-06 | 原型包含固定示例年度、静态示例数据和模拟趋势 | 正式系统应使用真实期间和正式数据 | 不把示例值当业务常量，优先验算公式和边界 |

PRD 中的以下公式与页面已有对应表现：

- 折标量 = 实物量 × 折标系数；
- 单位产品综合能耗 = 分配后的综合能耗（tce）÷ 产品产量；
- 对标偏差率 =（当前值 − 目标值）÷ 目标值 × 100%；
- 可供分配量、未分配量、超分配量；
- 转换折标差额 = Σ绝对值（投入折标量 − 产出折标量）。

PRD建议无效系数、缺失分母、无基数时显示“—”；原型示例数据部分可能返回 0 或固定状态，测试应记录为页面现状与业务期望的差异。

## 5. 建议执行的自动化和手工用例

建议按页面组织测试，不要求测试同事阅读源码或测试文件：能耗查询、能耗指标、能效对标、能流分析，以及能源品种、用能单元、重点设备、设备产出数据、能源消费、能源成本、能源转换回收与外供、运营数据。

必须覆盖的边界：

1. 月度部分月份有值且年度补录有值，年度结果取年度补录，不与月度相加。
2. 月度录入有值但该月未标记为已上报，该月不进入年度合计。
3. kgce 系数和 tce 系数各构造一条，确认只有 kgce 除以 1000。
4. 产品产量、工业总产值、建筑面积、设备产出为 0 或空，页面不得出现无穷大或非数值。
5. 对标方向分别为 high 和 low，确认达标判断相反。
6. 转换产出配置内部使用、外供、损失，验证三者之和。
7. 一级分配大于可供量、可供量大于一级分配，分别进入超分配和未分配。
8. 二级利用大于一级分配，显示层级异常或超分配，不生成负待分配量。
9. 设备产出缺月但有年度补录，设备年度指标使用补录值且不自动补月。
10. 成本台账只验证成本本身，不生成能源成本强度。
