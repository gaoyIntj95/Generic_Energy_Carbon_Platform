### 0.1 当前原型的数据说明

- 页面当前使用原型示例数据，首次进入页面会显示预置的能源品种、能源台账、用能单元和设备数据。
- 在数据管理页面录入或编辑后，当前页面会话内的分析结果应随之变化；刷新后是否保留属于正式系统的数据持久化方案，当前原型不作为业务承诺。
- 测试时应区分“页面录入数据”“页面预置示例数据”和“页面计算结果”，不需要关注数据在程序中的存储方式。

## 1. 页面一：能耗查询

页面入口：能源监测与分析 → 能耗查询。

### 1.1 页面级查询条件

#### 1.1.1 查询年份

```text
月度默认：最新年度的最新连续已上报月份（由能源台账动态计算）
年度默认：能源台账中的最新年度
年度下拉可选：能源台账中实际存在的年度，按倒序排列
显示精度：整数年，不取整计算
```

| 参数 | 含义 | 来源类型 | 来源明细 | 聚合/筛选方式 | 时间范围与粒度 |
| -- | -- | -- | -- | -- | -- |
| 查询时间 | 点击“查询”后生效的时间 | 用户输入 | 页面“时间”控件 | 按所选年度筛选；月度同时按所选月份筛选 | 月度或年度 |

边界规则：月度输入清空后点击查询，回退为最新年度的最新连续已上报月份；年度输入清空后回退为能源台账中的最新年度。年度选项来自能源台账，不固定为某个年份。非法或无法识别的时间输入，页面当前没有额外错误提示。

#### 1.1.2 查询月份

```text
月度模式：使用页面选择的月份
年度模式：统计该年度完整月份；如果是当前分析年度，则统计到最新连续已上报月份

显示：月度输入控件按“年-月”；年度模式只选择年份
```

| 参数 | 含义 | 来源类型 | 来源明细 | 聚合/筛选方式 | 时间范围与粒度 |
| -- | -- | -- | -- | -- | -- |
| 统计周期 | 月度或年度 | 用户输入 | 页面“月度/年度”按钮 | 按当前选择的周期统计 | 月/年 |
| 统计时间 | 年度或年月 | 用户输入 | 页面“时间”控件 | 年度模式按年筛选；月度模式按年月筛选 | 月/年 |

边界规则：当前分析年度不会把尚未连续上报的月份计入年度累计；历史年度按完整 12 个月处理。月度控件当前没有额外的最小/最大月份提示。

### 1.2 摘要卡

#### 1.2.1 综合能耗

```text
月度实物量：取当前筛选月份的能源实物量；未填写按 0 处理
年度实物量：
  当前分析年度：从 1 月累计到最新连续已上报月份
  历史年度：优先使用年度补录值，否则合计已上报月份实物量

折标量：
  原折标系数为 kgce/原始单位：实物量 × 原折标系数 ÷ 1000
  原折标系数为 tce/原始单位：实物量 × 原折标系数

综合能耗（tce） = Σ 各能源品种折标量

筛选范围：
  按所选年度筛选能源消费记录
  “全厂”只统计企业级能源消费记录，不把各用能单元再次相加
  选择用能单元时，只统计该用能单元的能源消费记录
  设备记录不重复计入全厂或用能单元综合能耗

显示：0 位小数，按中文千分位格式四舍五入
```

| 参数 | 含义 | 来源类型 | 来源明细 | 聚合/筛选方式 | 时间范围与粒度 |
| -- | -- | -- | -- | -- | -- |
| 月度/年度实物量 | 能源消费页面录入的实物量 | 页面输入 | 数据管理 → 能源消费 | 按已上报月份汇总 | 月/年 |
| 年度补录值 | 页面录入的年度台账总量 | 页面输入 | 数据管理 → 能源消费 | 大于 0 时优先用于历史年度年度值 | 年 |
| 折标系数 | 能源品种对应的折标系数 | 页面配置 | 数据管理 → 能源品种 | 按能源品种和年度匹配 | 年度配置 |
| 折标系数单位 | kgce/原始单位或 tce/原始单位 | 页面配置 | 数据管理 → 能源品种 | 决定是否进行 kgce→tce 换算 | 年度配置 |
| 分析年度 | 页面当前选择的年度 | 页面筛选 | 能耗查询顶部筛选区 | 精确筛选 | 年 |
| 分析月份 | 页面当前选择的月份 | 页面筛选 | 能耗查询顶部筛选区 | 月度精确取月；年度用于确定累计截止月 | 月/年 |
| 分析期间 | 能源台账中最新年度及连续已上报截止月 | 页面计算结果 | 数据管理 → 能源消费 | 当前年度按截止月累计 | 年/月 |

边界规则：找不到能源品种折标系数时该记录折标量按 0 处理；月值缺失按 0；总量允许为 0。负数当前没有额外拦截。全厂口径是企业级台账，不是各级用能单元之和。当前年度值按动态报数截止月累计。页面显示 0 位小数，但后续计算使用未显示的原始小数。

#### 1.2.2 同比变化

```text
上年同期值不为 0 时：同比(%) =（本期值 - 上年同期值）÷ 上年同期值 × 100；
上年同期值为 0 时：同比(%) = 0

当前年度：本期为当前年度 1—动态报数截止月；对比期为上年同期 1—同一截止月
其他年度：本期为本年全年；对比期为上年全年
月度：本期为本年所选月；对比期为上年同月

显示：1 位小数；正数前加“+”；页面箭头正数为 ↑，0 和负数为 ↓
```

| 参数 | 含义 | 来源类型 | 来源明细 | 聚合/筛选方式 | 时间范围与粒度 |
| -- | -- | -- | -- | -- | -- |
| 本期综合能耗 | 当前筛选期间的综合能耗 | 派生计算 | 按 1.2.1 计算 | 当前筛选 | 月/年 |
| 上年同期综合能耗 | 上年相同期间的综合能耗 | 派生计算 | 按 1.2.1 对上年相同期间计算 | 用能单元不变；当前年度按同一动态截止月对比 | 同期 |

边界规则：分母为 0 时返回 `0`，页面显示 `0.0%`，不是“--”。结果不设上下限。0 被渲染成向下箭头。

#### 1.2.3 环比变化

```text
上月值不为 0 时：环比(%) =（本月值 - 上月值）÷ 上月值 × 100；
上月值为 0 时：环比(%) = 0

仅月度模式展示。
显示：1 位小数；正数前加“+”；正数为 ↑，0 和负数为 ↓
```

| 参数 | 含义 | 来源类型 | 来源明细 | 聚合/筛选方式 | 时间范围与粒度 |
| -- | -- | -- | -- | -- | -- |
| 本月综合能耗 | 当前筛选月份的综合能耗 | 派生计算 | 按 1.2.1 计算 | 当前筛选 | 月 |
| 上月综合能耗 | 同年度上一个月的综合能耗 | 派生计算 | 按 1.2.1 对上一个月计算 | 同一用能单元 | 上月 |

边界规则：1 月没有上月对象，返回 0；上月总量为 0 也返回 0；均显示 `0.0%` 而不是“--”。

### 1.3 能源消费趋势

#### 1.3.1 每个柱的综合能耗

```text
月度模式：
  每个月柱值 = 按 1.2.1 重算该年度该月综合能耗
  从 1 月生成到当前选择月份

年度模式：
  每年柱值 = 按 1.2.1 重算该年度综合能耗
  展示当前选择年度及前 4 个年度
  当前分析年度仅累计到最新连续已上报月份

显示值：0 位小数，zh-CN 千分位
柱高 = 趋势值 ÷（最大趋势值与 1 中的较大值 × 图形留白系数）× 绘图区高度，再取整
```

| 参数 | 含义 | 来源类型 | 来源明细 | 聚合/筛选方式 | 时间范围与粒度 |
| -- | -- | -- | -- | -- | -- |
| 趋势柱值 | 对应月份或年度的综合能耗 | 派生计算 | 按 1.2.1 计算 | 月度从 1 月生成到所选月；年度展示 5 个年度 | 月/年 |
| 图形高度参数 | 图形留白和绘图区高度 | 页面显示规则 | 页面图表样式 | 只影响柱高，不改变显示数值 | 当前图 |

边界规则：最大值至少按 1 计算，避免全 0 时无法绘制；负值当前没有额外限制。标题按当前查询年度和月份动态生成，与筛选联动。

### 1.4 能源结构

#### 1.4.1 圆环中心综合能耗

```text
圆环中心值 = 综合能耗
显示：0 位小数，zh-CN 千分位
```

| 参数 | 含义 | 来源类型 | 来源明细 | 聚合/筛选方式 | 时间范围与粒度 |
| -- | -- | -- | -- | -- | -- |
| `综合能耗` | 本期总折标量 | 派生计算 | 见 1.2.1 | 当前筛选 | 月/年 |

边界规则：与摘要卡同值；空数据时显示 `0 tce`。

#### 1.4.2 各能源品种折标量

```text
能源品种折标量 = Σ 当前能源品种明细行折标量

显示：0 位小数，zh-CN 千分位
```

| 参数 | 含义 | 来源类型 | 来源明细 | 聚合/筛选方式 | 时间范围与粒度 |
| -- | -- | -- | -- | -- | -- |
| 明细行折标量 | 当前能源品种的折标量 | 派生计算 | 见 1.5.3 | 按能源品种名称归类汇总 | 当前期间 |
| 能源品种名称 | 能源品种展示名称 | 页面配置 | 数据管理 → 能源品种 | 名称相同的明细行合并 | 年度配置 |

边界规则：同名但编码不同的能源品种仍会被合并；显示四舍五入到整数，圆环计算仍使用原始值。

#### 1.4.3 各能源品种占比与圆环扇区

```text
综合能耗不为 0 时：品种占比(%) = 品种折标量 ÷ 综合能耗 × 100；
综合能耗为 0 时：品种占比(%) = 0

扇区起点 = Σ 当前项之前各项占比
扇区终点 = 扇区起点 + 当前项占比

占比显示：1 位小数
圆环颜色：按首次出现顺序循环使用 5 个写死颜色
```

| 参数 | 含义 | 来源类型 | 来源明细 | 聚合/筛选方式 | 时间范围与粒度 |
| -- | -- | -- | -- | -- | -- |
| 品种折标量 | 品种折标汇总 | 派生计算 | 见 1.4.2 | 当前品种 | 当前期间 |
| 综合能耗 | 总折标量 | 派生计算 | 见 1.2.1 | 当前筛选 | 当前期间 |
| 扇区颜色 | 页面图表颜色 | 页面显示规则 | 按能源品种出现顺序循环使用预置颜色 | 仅影响图形，不改变数值 | 当前图 |

边界规则：总量为 0 时所有占比为 0。显示值逐项四舍五入后不保证合计正好 100.0%，但扇区使用未取整原值。

| 参数 | 含义 | 来源类型 | 来源明细 | 聚合/筛选方式 | 时间范围与粒度 |
| -- | -- | -- | -- | -- | -- |
| 实际日数 | 原型生成的日明细数量 | 原型示例规则 | 固定为 30 条 | 计数 | 日 |
| 应有日数 | 所选月份的公历天数 | 页面计算结果 | 按所选年月确定 | 计数 | 月 |
| 当前分析期间 | 最新年度和最新连续已上报月份 | 页面计算结果 | 当前期间显示“进行中” | 当前期间 | 月 |

边界规则：当前分析期间即使有 30 条也显示“进行中”，不显示“完整”；非 30 天月份会显示“缺失”，原因是模拟日明细固定 30 条。

#### 1.7.5 每日实物量

```text
总权重 = Σ 30 个日分配权重
日实物量原值 = 月实物量 × 当日权重 ÷ 总权重
先取整，再按小数部分从大到小补足余数
每日实物量 = 取整后的分摊值
```

| 参数 | 含义 | 来源类型 | 来源明细 | 聚合/筛选方式 | 时间范围与粒度 |
| -- | -- | -- | -- | -- | -- |
| 月实物量 | 本月行实物量 | 派生计算 | 见 1.5.2 | 当前行 | 月 |
| 当日分配权重 | 原型预置的日分配权重 | 原型示例规则 | 按权重比例分摊并用最大余数法补整数 | 日 |

边界规则：这是模拟值，不是日计量数据。每日分配合计等于月实物量四舍五入后的整数，小数部分可能丢失。

#### 1.7.6 每日折标量

```text
按与 1.7.5 相同的整数分配算法：
每日折标量 = 按与每日实物量相同的整数分配方法分摊月折标量
```

| 参数 | 含义 | 来源类型 | 来源明细 | 聚合/筛选方式 | 时间范围与粒度 |
| -- | -- | -- | -- | -- | -- |
| 月折标量 | 本月行折标量 | 派生计算 | 见 1.5.3 | 当前行 | 月 |
| 当日分配权重 | 原型预置的日分配权重 | 原型示例规则 | 最大余数法整数分摊 | 日 |

边界规则：模拟值合计等于月折标量四舍五入后的整数，可能不等于原始未取整月折标量。

#### 1.7.7 较日均偏差

```text
日均折标量 = 月折标量 ÷ 30
较日均偏差(%) =（每日折标量 - 日均折标量）÷ 日均折标量 × 100
显示：1 位小数，正数加“+”
```

| 参数 | 含义 | 来源类型 | 来源明细 | 聚合/筛选方式 | 时间范围与粒度 |
| -- | -- | -- | -- | -- | -- |
| 每日折标量 | 模拟日折标量 | 派生计算 | 见 1.7.6 | 当前日 | 日 |
| 月折标量 | 月折标量原值 | 派生计算 | 见 1.5.3 | 除以固定 30 | 月 |

边界规则：月折标量为 0 时会发生“0 除以 0”，偏差可能显示为非数值；当前页面没有除零保护。

#### 1.7.8 日数据状态徽标

```text
状态 = 较日均偏差 ≥ 12% 时“偏高”；
      较日均偏差 ≤ -12% 时“偏低”；否则“正常”
```

| 参数 | 含义 | 来源类型 | 来源明细 | 聚合/筛选方式 | 时间范围与粒度 |
| -- | -- | -- | -- | -- | -- |
| 较日均偏差 | 较日均偏差 | 派生计算 | 见 1.7.7 | 当前日 | 日 |
| 状态阈值 | +12% 和 -12% | 页面显示规则 | 含边界 | 日 |

边界规则：偏差为非数值时不满足两侧判断，最终显示“正常”。

#### 1.7.9 日度趋势柱高

```text
柱高(%) = 每日折标量 ÷ 峰值日折标量 × 100%，最低显示高度为 18%
```

| 参数 | 含义 | 来源类型 | 来源明细 | 聚合/筛选方式 | 时间范围与粒度 |
| -- | -- | -- | -- | -- | -- |
| 每日折标量 | 模拟日折标量 | 派生计算 | 见 1.7.6 | 当前日 | 日 |
| 峰值日折标量 | 日折标最大值 | 派生计算 | 见 1.7.3 | 30 日最大 | 日 |
| 最小可视高度 | 18% | 页面显示规则 | 仅影响图形 | 当前图 |

边界规则：峰值为 0 时会发生“0 除以 0”，页面样式可能显示为非数值。

#### 1.7.10—1.7.12 日明细合计三项

```text
合计实物量 = 月实物量
合计折标量 = 月折标量
合计状态 = 日数据完整性状态
```

| 参数 | 含义 | 来源类型 | 来源明细 | 聚合/筛选方式 | 时间范围与粒度 |
| -- | -- | -- | -- | -- | -- |
| 月实物量 | 月实物量 | 派生计算 | 见 1.5.2 | 当前行 | 月 |
| 月折标量 | 月折标量 | 派生计算 | 见 1.5.3 | 当前行 | 月 |
| 完整性状态 | 日数据完整性 | 派生计算 | 见 1.7.4 | 当前月 | 月 |

边界规则：合计使用原始月值，而明细使用整数分摊值，因此明细逐日求和可能与合计显示不一致。合计“较日均”固定显示“—”。
