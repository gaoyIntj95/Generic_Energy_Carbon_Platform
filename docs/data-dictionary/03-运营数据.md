# 运营数据：树状结构与对应字典

> 本文是“数据管理 → 运营数据”的研发沟通稿。字典与业务树逐节点对应；字段名沿用当前前端 `V11OperationMetric` 和产品主数据。

## 1. 业务树

```text
数据管理
└── 运营数据
    ├── 查询条件
    │   ├── 年度
    │   ├── 指标类别
    │   └── 关键词
    ├── 层级视图
    │   ├── 全部层级（只读总览）
    │   ├── 企业
    │   ├── 一级用能单元
    │   └── 二级用能单元
    └── 运营记录
        ├── 产量指标
        │   └── 产品产量
        │       ├── 产品主数据
        │       ├── 归属范围
        │       ├── 月度值
        │       └── 年度值
        ├── 运行指标
        │   ├── 动力中心供能量
        │   ├── 办公建筑面积
        │   ├── 货物吞吐量
        │   └── 运营量
        └── 经济指标
            ├── 工业总产值
            └── 工业增加值
```

## 2. 树节点字典

| 节点编码 | 节点名称 | 节点类型 | 父节点 | 对应对象/字段 | 说明 |
|---|---|---|---|---|---|
| `data_management` | 数据管理 | 一级菜单 | — | — | 数据维护一级菜单。 |
| `operations` | 运营数据 | 页面 | `data_management` | — | 维护产量、运行指标和经济指标。 |
| `operation_filters` | 查询条件 | 页面分区 | `operations` | — | 用于筛选列表，不产生运营记录。 |
| `filter_year` | 年度 | 查询字段 | `operation_filters` | `year` | 必填；新增记录默认继承当前查询年度。 |
| `filter_category` | 指标类别 | 查询字段 | `operation_filters` | `metricCategory` | 产量指标、运行指标、经济指标。 |
| `filter_keyword` | 关键词 | 查询字段 | `operation_filters` | — | 匹配产品名称、归属范围或指标名称。 |
| `scope_views` | 层级视图 | 页面分区 | `operations` | `scopeLevel` | 运营记录按归属层级查看。 |
| `scope_all` | 全部层级 | 只读视图 | `scope_views` | — | 跨层级查看，不提供新增入口，不做跨层级自动汇总。 |
| `scope_enterprise` | 企业 | 维护视图 | `scope_views` | `scopeLevel='企业'` | 归属范围固定为全厂；经济指标只能在此维护。 |
| `scope_level1` | 一级用能单元 | 维护视图 | `scope_views` | `scopeLevel='一级用能单元'` | 按一级用能单元分组，可新增产量和运行指标。 |
| `scope_level2` | 二级用能单元 | 维护视图 | `scope_views` | `scopeLevel='二级用能单元'` | 按二级用能单元分组，是否允许产品产量需按当前版本规则确认。 |
| `operation_records` | 运营记录 | 页面分区 | `operations` | `V11OperationMetric` | 一条记录对应一个年度、一个归属范围、一个指标口径。 |
| `production` | 产量指标 | 指标类别 | `operation_records` | `metricCategory='产量指标'` | 作为产品能耗等指标的业务分母。 |
| `product_output` | 产品产量 | 指标口径 | `production` | `metricCode='product_output'` | 必须关联产品；名称通常为“产品产量”。 |
| `product_master` | 产品主数据 | 关联对象 | `product_output` | `productId` | 选择已有产品时带出名称、类别和单位；自定义产品需单独确认是否落产品主数据。 |
| `production_scope` | 归属范围 | 业务关系 | `product_output` | `scopeLevel` / `energyUnitId` | 企业为全厂；非企业层级必须关联用能单元。 |
| `production_monthly` | 月度值 | 业务字段 | `product_output` | `monthlyValues` / `monthlyReportedMonths` | 1—12 月；已填月份汇总年度值，空白与 0 分开。 |
| `production_annual` | 年度值 | 业务字段 | `product_output` | `annualValue` | 月度未填满时可补录；不得把年度值分摊到月份。 |
| `operating` | 运行指标 | 指标类别 | `operation_records` | `metricCategory='运行指标'` | 使用页面预置指标，不允许自由定义名称和单位。 |
| `energy_supply` | 动力中心供能量 | 预置指标 | `operating` | `metricCode='energy_supply'` | 月度填报，单位 `GJ`。 |
| `building_area` | 办公建筑面积 | 预置指标 | `operating` | `metricCode='building_area'` | 年度静态值，单位 `m²`，不设置月度明细。 |
| `logistics_throughput` | 货物吞吐量 | 预置指标 | `operating` | `metricCode='logistics_throughput'` | 月度填报，单位由预置口径确定。 |
| `business_volume` | 运营量 | 预置指标 | `operating` | `metricCode='business_volume'` | 月度填报，单位由预置口径确定。 |
| `economic` | 经济指标 | 指标类别 | `operation_records` | `metricCategory='经济指标'` | 仅企业级年度填报，单位为万元。 |
| `industrial_output_value` | 工业总产值 | 预置指标 | `economic` | `metricCode='industrial_output_value'` | 企业全厂年度值。 |
| `industrial_added_value` | 工业增加值 | 预置指标 | `economic` | `metricCode='industrial_added_value'` | 企业全厂年度值。 |
| `operation_detail` | 月度明细 | 查看区域 | `operation_records` | `monthlyValues` | 查看只读；年度型指标显示暂无月度数据。 |
| `operation_actions` | 操作 | 操作区域 | `operation_records` | — | 查看、编辑、删除；删除需提示影响相关分析。 |

## 3. 记录字段字典

| 字段 | 类型 | 对应树节点 | 说明 |
|---|---|---|---|
| `operationMetricId` | string | 运营记录 | 记录主键。 |
| `metricCode` | string | 指标口径 | 稳定指标编码；不以页面显示名称作为唯一关联条件。 |
| `metricCategory` | 枚举 | 指标类别 | `产量指标` / `运行指标` / `经济指标`。 |
| `metricName` | string | 指标口径 | 指标显示名称；预置指标不允许自由修改。 |
| `productId` | string \| null | 产品主数据 | 只有产品产量使用；经济、运行指标为空。 |
| `year` | number | 所属年度 | 记录所属年度。 |
| `scopeLevel` | 枚举 | 层级视图 | `企业` / `一级用能单元` / `二级用能单元`。 |
| `energyUnitId` | string \| null | 归属范围 | 企业层级为空，其他层级关联同年度用能单元。 |
| `aggregationMethod` | 枚举 | 月度值/年度值 | `月度求和` / `年度单值`。 |
| `entryMode` | 枚举 | 月度值/年度值 | `monthly` / `annual`；表示实际录入方式。 |
| `metricUnit` | string | 指标口径 | 产品单位来自产品主数据；预置运行/经济指标使用固定单位。 |
| `monthlyValues` | number[] | 月度值 | 月度记录通常为 12 个月；年度型指标可为空数组。 |
| `monthlyReportedMonths` | boolean[] | 月度值 | 标识实际填报月份；明确填报 0 仍为已填报。 |
| `annualValue` | number | 年度值 | 月度填满时由系统汇总；未填满时允许年度补录。 |

## 4. 树上的关键约束

| 树关系 | 约束 |
|---|---|
| 层级视图 → 新增 | “全部层级”仅查看；新增必须进入企业、一级或二级具体层级视图。 |
| 指标类别 → 归属层级 | 产量指标和运行指标可按企业/一级/二级维护；经济指标只能企业级、全厂范围、年度填报。 |
| 产品产量 → 产品主数据 | 产品产量必须关联产品；同一产品同一年度只能采用企业汇总或用能单元拆分一种口径，不能并存。 |
| 二级用能单元 → 产品产量 | 业务文档允许具备独立产量口径的二级单元维护；当前 mock 保存逻辑对 `product_output` 的二级记录有限制，正式研发需确认最终口径。 |
| 运行指标 → 指标预置 | 名称和单位由预置定义；办公建筑面积为年度静态值，其余预置运行指标按月度维护。 |
| 月度值 → 年度值 | 月度已填报值汇总年度值；年度补录值不得反向分摊到月份。 |
| 运营记录 → 记录唯一性 | 同一年度、同一归属范围、同一指标口径、同一产品只能有一条记录。 |
| 删除 → 下游分析 | 删除会影响能耗强度、能效对标、用能分析等结果，页面需给出影响提示。 |
