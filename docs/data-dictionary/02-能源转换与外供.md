# 能源转换回收与外供：树状结构与对应字典

> 本文是“数据管理 → 能源数据 → 能源转换回收与外供”的研发沟通稿。
> 字典与业务树逐节点对应；字段名沿用当前前端 mock store，稳定编码可在接口设计时确认。

## 1. 业务树

```text
数据管理
└── 能源数据
    └── 能源转换回收与外供
        ├── 转换与回收清单
        │   └── 转换产出记录
        │       ├── 所属年度
        │       ├── 转换系统
        │       │   └── 二级用能单元
        │       ├── 投入能源
        │       │   ├── 能源消费记录
        │       │   └── 回收能源记录/来源
        │       ├── 产出能源
        │       │   └── 能源品种
        │       ├── 月度产出
        │       ├── 已确认损失
        │       ├── 月度外供汇总
        │       └── 厂内可供量
        └── 外供记录
            └── 外供台账
                ├── 所属年度
                ├── 供能来源
                │   ├── 企业级能源消费记录
                │   └── 转换产出记录
                ├── 外供能源品种与单位
                ├── 接收方
                ├── 月度外供数量
                ├── 核验状态
                └── 备注/凭证
```

## 2. 树节点字典

| 节点编码 | 节点名称 | 节点类型 | 父节点 | 对应对象/字段 | 说明 |
|---|---|---|---|---|---|
| `data_management` | 数据管理 | 一级菜单 | — | — | 数据维护一级菜单。 |
| `energy_data` | 能源数据 | 二级菜单 | `data_management` | — | 能源消费、成本、转换与外供共用入口。 |
| `energy_conversion_supply` | 能源转换回收与外供 | 页面 | `energy_data` | — | 统一维护转换产出、回收、损失及外供。 |
| `conversion_list` | 转换与回收清单 | 页面分区 | `energy_conversion_supply` | — | 展示转换系统及其产出记录。 |
| `conversion_output` | 转换产出记录 | 业务实体 | `conversion_list` | `V11ConversionOutput` | 一条记录表示一个年度内、一个二级用能单元的一种产出能源。 |
| `conversion_year` | 所属年度 | 业务字段 | `conversion_output` | `year` | 所有投入、产出、损失必须与记录同年度。 |
| `conversion_system` | 转换系统 | 业务关系 | `conversion_output` | `conversionEnergyUnitId` | 关联二级用能单元；本页不新增或删除用能单元。 |
| `conversion_input` | 投入能源 | 业务关系 | `conversion_output` | `inputMode` | 投入只能来自同年度、同一二级用能单元的能源消费或回收能源记录。 |
| `input_consumption` | 能源消费记录 | 来源节点 | `conversion_input` | `inputEnergyRecordId` | 已有能源消费记录的 ID；不能引用设备消费。 |
| `input_recovery` | 回收能源记录/来源 | 来源节点 | `conversion_input` | `inputEnergyRecordId` / `recoverySourceEnergyUnitId` | 优先引用回收能源记录；没有现成记录时补充来源信息。 |
| `conversion_output_energy` | 产出能源 | 业务关系 | `conversion_output` | `outputEnergyTypeId` | 从当前年度能源品种中选择，名称和单位由能源品种带出。 |
| `monthly_output` | 月度产出 | 业务字段 | `conversion_output` | `monthlyOutputAmounts` / `monthlyOutputReported` | 12 个月维护；空白与明确填报 0 分开，年度值不分摊。 |
| `confirmed_loss` | 已确认损失 | 业务字段 | `conversion_output` | `monthlyLossAmounts` / `monthlyLossReported` | 空白不等于确认 0；可填写损失依据 `lossBasis`。 |
| `monthly_external_total` | 月度外供汇总 | 派生字段 | `conversion_output` | `monthlyExternalAmounts` | 汇总关联外供台账，不直接编辑。 |
| `internal_available` | 厂内可供量 | 派生字段 | `conversion_output` | `monthlyInternalAmounts` / `internalAmount` | `产出 − 有效外供 − 已确认损失`，展示值最小为 0。 |
| `external_list` | 外供记录 | 页面分区 | `energy_conversion_supply` | — | 展示转换产出外供和企业能源直接外供。 |
| `external_supply` | 外供台账 | 业务实体 | `external_list` | `V11ExternalSupplyRecord` | 一条记录对应一个来源、一个接收方及一组年度月度数量。 |
| `external_year` | 所属年度 | 业务字段 | `external_supply` | `year` | 必须与供能来源年度一致。 |
| `external_source` | 供能来源 | 业务关系 | `external_supply` | `inputEnergyRecordId` / `conversionOutputId` | 二选一：企业级能源消费记录或转换产出记录。 |
| `enterprise_source` | 企业级能源消费记录 | 来源节点 | `external_source` | `inputEnergyRecordId` | 只能关联企业级能源输入，不能关联厂内单元或设备数据。 |
| `conversion_source` | 转换产出记录 | 来源节点 | `external_source` | `conversionOutputId` | 关联本页转换产出记录。 |
| `external_energy` | 外供能源品种与单位 | 业务字段 | `external_supply` | `energyTypeId` / `unit` | 从来源继承；外供单位必须与来源单位一致。 |
| `receiver` | 接收方 | 业务字段 | `external_supply` | `receiver` | 企业外部接收方，必填。 |
| `monthly_external` | 月度外供数量 | 业务字段 | `external_supply` | `monthlyAmounts` / `monthlyReported` | 12 个月维护；空白显示“—”，明确填报 0 显示 0。 |
| `verification_status` | 核验状态 | 派生状态 | `external_supply` | `flowExternalIssue` | 来源缺失或月度外供超量时为待核验；待核验不进入有效能流。 |
| `remark_evidence` | 备注/凭证 | 辅助字段 | `external_supply` | `remark` / `evidenceNames` | 凭证字段当前仅保存文件名，正式版接附件元数据。 |

## 3. 树节点枚举字典

### 3.1 转换系统场景

| 当前值（`recordType`） | 建议编码 | 对应树节点 | 说明 |
|---|---|---|---|
| `锅炉产汽/产热` | `boiler_steam_heat` | `conversion_system` | 例如天然气 → 蒸汽。 |
| `余热发电` | `waste_heat_power` | `conversion_system` | 回收能源投入，产出通常为电力。 |
| `空压产气/压缩空气` | `compressed_air` | `conversion_system` | 系统级产出，不自动累加设备产出。 |
| `回收利用` | `recovery` | `conversion_system` | 例如余热利用、余压回收。 |
| `其他转换` | `other_conversion` | `conversion_system` | 由投入能源和产出能源明确实际关系。 |
| `直接外供` | `direct_supply` | `external_source` | 仅兼容历史记录；新版外供使用外供台账。 |

### 3.2 投入模式

| 当前值（`inputMode`） | 对应树节点 | 说明 |
|---|---|---|
| `linked` | `input_consumption` | 关联能源消费记录。 |
| `recovery` | `input_recovery` | 关联回收能源记录。 |
| `manual` | `input_recovery` | 没有现成记录时人工补充回收来源，兼容历史数据。 |
| `none` | `conversion_input` | 无投入历史记录，不作为有效能流投入。 |
| `direct` | `external_source` | 兼容直接外供历史记录。 |

## 4. 树上的关键约束

| 树关系 | 约束 |
|---|---|
| 转换系统 → 投入能源 | 必须是同年度、同一二级用能单元的能源消费/回收记录；同一投入不可重复绑定。 |
| 转换系统 → 产出能源 | 同一年度、同一系统、同一产出能源只能有一条转换产出记录。 |
| 外供记录 → 供能来源 | `inputEnergyRecordId` 与 `conversionOutputId` 只能有一个有值。 |
| 外供记录 → 月度数量 | 同一来源逐月累计不得超过来源当月可供量；来源缺失时可保存但必须待核验。 |
| 产出 → 厂内可供量 | 厂内可供量为派生值，不允许手工录入。 |
| 年度 → 月度 | 缺失月份不使用年度值平均或按比例分摊。 |
| 能源品种 | “回收蒸汽”不作为独立品种，统一使用“蒸汽”；回收来源通过投入关系追溯。 |
