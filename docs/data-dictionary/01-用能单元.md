# 用能单元页面：关系树与字典

> 本文作为“用能单元页面”的研发沟通稿。页面尚未正式实现时，以本文确定的层级关系和字典命名为准。

## 1. 关系树

### 1.1 业务分类层

```text
用能单元
├── 生产类用能单元
└── 非生产类用能单元
```

“生产类用能单元”和“非生产类用能单元”是业务分类，不单独保存为可编辑的用能单元记录。

### 1.2 生产类关系

```text
生产类用能单元
└── 生产单元（一级用能单元）
    └── 工序/环节（二级用能单元）
```

示例：

```text
生产类用能单元
└── 生产车间A（生产单元）
    ├── 原料处理（工序/环节）
    ├── 生产加工（工序/环节）
    └── 包装发运（工序/环节）
```

### 1.3 非生产类关系

```text
非生产类用能单元
├── 能源转换系统（一级用能单元）
│   └── 能源转换子系统（二级用能单元）
├── 建筑区域（一级用能单元）
│   └── 建筑子区域（二级用能单元，可选）
├── 空调服务系统（一级用能单元）
│   └── 区域空调服务单元（二级用能单元）
└── 其他（一级用能单元）
```

示例：

```text
非生产类用能单元
├── 动力中心（能源转换系统）
│   ├── 锅炉系统（能源转换子系统）
│   └── 空压系统（能源转换子系统）
├── 办公区域（建筑区域）
│   └── 办公楼A区（建筑子区域）
├── 空调服务系统（空调服务系统）
│   └── 办公区域空调服务（区域空调服务单元）
└── 仓储物流区域（其他）
```

### 1.4 重要边界

- 分类层不生成 `energy_unit_id`，只通过 `root_category` 表示。
- 实际用能单元最多两级：一级用能单元、二级用能单元。
- `建筑区域` 下只能配置 `建筑子区域`，不能配置 `能源转换子系统`。
- `能源转换子系统` 只能挂在 `能源转换系统` 下。
- `区域空调服务单元` 只能挂在 `空调服务系统` 下，且不能继续添加下级。
- `工序/环节` 只能挂在 `生产单元` 下。
- `其他` 暂不提供二级子类型，也不能继续添加下级。
- 用能单元按年度维护，年度之间的层级和归属互不覆盖。

## 2. 字典表

### 2.1 业务分类字典

| 字典类型 | 编码 | 名称 | 是否实体记录 | 说明 |
|---|---|---|---|---|
| root_category | `production` | 生产类用能单元 | 否 | 对应一级类型“生产单元” |
| root_category | `non_production` | 非生产类用能单元 | 否 | 对应一级类型“能源转换系统”“建筑区域”“空调服务系统”“其他” |

### 2.2 用能单元层级字典

| 字典类型 | 编码 | 名称 | 适用范围 | 父级限制 | 说明 |
|---|---|---|---|---|---|
| unit_level | `level1` | 一级用能单元 | 实体记录 | 企业/组织 | 可新增、编辑、删除 |
| unit_level | `level2` | 二级用能单元 | 实体记录 | 一级用能单元 | 最多两级，不能继续添加下级 |

### 2.3 用能单元类型字典

| 字典类型 | 编码 | 显示名称 | 适用层级 | 允许的父级 | 所属分类 |
|---|---|---|---|---|---|
| unit_type | `production_unit` | 生产单元 | 一级 | 企业/组织 | 生产类 |
| unit_type | `process_stage` | 工序/环节 | 二级 | 生产单元 | 生产类 |
| unit_type | `energy_conversion_system` | 能源转换系统 | 一级 | 企业/组织 | 非生产类 |
| unit_type | `energy_conversion_subsystem` | 能源转换子系统 | 二级 | 能源转换系统 | 非生产类 |
| unit_type | `building_area` | 建筑区域 | 一级 | 企业/组织 | 非生产类 |
| unit_type | `building_subarea` | 建筑子区域 | 二级 | 建筑区域 | 非生产类 |
| unit_type | `air_conditioning_service_system` | 空调服务系统 | 一级 | 企业/组织 | 非生产类 |
| unit_type | `regional_air_conditioning_service_unit` | 区域空调服务单元 | 二级 | 空调服务系统 | 非生产类 |
| unit_type | `other` | 其他 | 一级 | 企业/组织 | 非生产类 |

> 命名调整：原先一级、二级共用的“建筑/区域”拆分为“建筑区域”和“建筑子区域”；“建筑区域”不再允许选择“能源转换子系统”。能源回收、转换利用相关单元统一归入“能源转换系统—能源转换子系统”；空调相关单元统一归入“空调服务系统—区域空调服务单元”。

空调服务单元的服务对象通过 `service_area_ids` 关联实际建筑区域、生产单元或其他区域，不再通过继续增加下级表达服务范围。

### 2.4 能源转换场景字典

仅对二级 `energy_conversion_subsystem` 展示和维护：

| 字典类型 | 编码 | 显示名称 | 适用类型 | 说明 |
|---|---|---|---|---|
| conversion_scenario | `boiler_steam_heat` | 锅炉产汽/产热 | 能源转换子系统 | 仅作为转换系统候选标签 |
| conversion_scenario | `waste_heat_power` | 余热发电 | 能源转换子系统 | 仅作为转换系统候选标签 |
| conversion_scenario | `compressed_air` | 空压产气/压缩空气 | 能源转换子系统 | 仅作为转换系统候选标签 |
| conversion_scenario | `recovery` | 回收利用 | 能源转换子系统 | 仅作为转换系统候选标签 |
| conversion_scenario | `other_conversion` | 其他转换 | 能源转换子系统 | 仅作为转换系统候选标签 |

转换场景不是用能单元层级，也不代表实际能流关系；实际能源投入、产出和数量仍由能源数据页面维护。

## 3. 后端判断关系

后端保存实体记录时，建议同时保存：

```text
tenant_id
organization_id
year
energy_unit_id
energy_unit_name
parent_unit_id
root_category
unit_level
unit_type
display_order
status
remark
```

关键校验：

| 场景 | 允许关系 |
|---|---|
| 新增一级生产类 | `root_category=production` + `unit_type=production_unit` |
| 新增二级生产类 | 父级 `unit_type=production_unit` + `unit_type=process_stage` |
| 新增一级能源转换类 | `root_category=non_production` + `unit_type=energy_conversion_system` |
| 新增二级能源转换类 | 父级 `unit_type=energy_conversion_system` + `unit_type=energy_conversion_subsystem` |
| 新增一级建筑类 | `root_category=non_production` + `unit_type=building_area` |
| 新增二级建筑类 | 父级 `unit_type=building_area` + `unit_type=building_subarea` |
| 新增一级空调服务类 | `root_category=non_production` + `unit_type=air_conditioning_service_system` |
| 新增二级空调服务类 | 父级 `unit_type=air_conditioning_service_system` + `unit_type=regional_air_conditioning_service_unit` |
| 新增一级其他类 | `root_category=non_production` + `unit_type=other` |

同一租户、同一年度、同一父级下，用能单元名称必须唯一。跨表关联统一使用 `energy_unit_id`，不使用名称匹配。
