# 数据源地图审计

> 下表是根据 HTML 中字段、计算提示和跨页链接推断的业务依赖，不代表已确认的接口设计。原型没有真实 API、数据库或数据责任人信息。

| 数据对象 | 产生/维护位置 | 被哪些模块使用 | 依赖与计算 |
|---|---|---|---|
| 用能单元层级 | 数据管理 → 用能单元 | 能源消费、运营数据、重点设备、能源监测、能效平衡、碳核算边界 | 一级/二级归属控制可选范围；层级改变会影响汇总粒度 |
| 能源品种 | 数据管理 → 能源品种 | 能源消费、能源成本、特殊能源关系、重点设备、能流分析、碳核算活动数据 | 计量单位、折标系数、折标单位用于统一 tce 计算 |
| 能源消费 | 数据管理 → 能源数据 / 能源消费 Tab | 能源监测、能效平衡、预算、能流分析、碳核算 | 月度值可汇总年度值；归属范围构成普通能源分配基础 |
| 能源成本 | 数据管理 → 能源数据 / 能源成本 Tab | 用能分析与策略推荐、预算分析 | 1—12 月成本自动汇总年度成本 |
| 特殊能源关系 | 数据管理 → 能源数据 / 特殊能源关系 Tab | 能流分析、能源平衡、能效平衡 | 关系记录引用已有能源消费/产出数据；普通分配由能源消费归属自动形成 |
| 运营数据 | 数据管理 → 运营数据 | 能耗强度指标、能效对标、用能分析 | 一期主要采集产量、业务量、经济指标，用于单位产品能耗和经营分析 |
| 重点设备 | 数据管理 → 重点设备 | 能源监测、能效分析、可能的碳核算边界 | 原型只确认设备与用能单元、能源品种的关联 |
| 折标数据 | 能源品种 + 能源消费 | 能流分析、能源平衡、能效平衡、预算 | 各能源品种通过折标系数转换为 tce |
| 碳核算任务/边界 | 碳核算 → 新建任务/核算设置 | 碳核算清单、核查支撑、碳排预览、报告 | 任务年度、主体、行业方法、核算范围决定清单内容 |
| 排放源活动数据 | 碳核算 → 碳核算清单 | 碳排预览、核查支撑、碳排报告、预算/资产预测（依赖关系需确认） | 活动数据 × 排放因子形成排放量；缺失时显示待计算或待补充 |
| 排放因子 | 碳因子库 | 碳核算清单与排放量结果 | 因子有标准来源、类型、单位、数值、适用范围和状态 |
| 核查支撑材料 | 碳核查支撑 | 排放源详情、核查流程、可能的报告 | 排放源支撑清单由核算清单自动生成；材料状态影响“已上传/待补充” |
| 碳排放结果 | 碳排放预览/核算清单计算结果 | 碳预算、碳资产、报告、能碳策略 | 原型展示 tCO₂e；具体是否实时计算、计算版本和锁定机制未确认 |
| 能源预算 | 能碳资产运营 → 预算管理 | 预算趋势、预算执行表、AI 建议 | 目标、累计、预测全年、偏差和风险状态；能源单位为 tce |
| 碳排放预算 | 能碳资产运营 → 预算管理 | 预算趋势、预算执行表、AI 建议、碳资产 | 与碳排结果/预测存在业务依赖，但原型未给出明确接口映射 |
| 碳配额/CCER/绿证折算减排量 | 能碳资产运营 → 碳资产管理 | 履约状态、缺口趋势、资产台账、测算 | 已分配、已使用、剩余、预计排放和缺口共同形成履约判断 |
| 资产测算结果 | 碳资产 → 新周期配额测算 | 新周期测算摘要、资产策略 | 基准历史排放、初步测算配额和周期变化；公式与政策参数未确认 |

## 四模块依赖关系

```text
数据管理
  ├─ 用能单元 + 能源品种 + 能源消费 + 特殊能源关系 + 运营数据
  │       └─> 能源监测与分析
  │               ├─> 能效平衡 / 用能分析 / 预算输入
  │               └─> 能碳资产运营与策略
  └─> 碳排放核算与合规（活动数据来源、核算边界需进一步确认）

碳排放核算与合规
  ├─ 碳核算任务 + 排放源活动数据 + 碳因子库
  └─> 核查支撑、碳排结果、报告
          └─> 碳预算与碳资产履约判断（原型未完全确认）

能源监测与分析 + 碳排放核算与合规
  └─> 能碳资产运营与策略
       ├─ 能效平衡、策略推荐
       ├─ 能源/碳排放预算
       └─ 碳资产与履约缺口
```
